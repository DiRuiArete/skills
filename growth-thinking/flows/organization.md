# 组织诊断流 — 产出：难度-强度匹配 + 关系/容纳度诊断 + 信息环境修复 + 阶段要点

## 输入
先查 plan 文件「已确认事实」：已知团队规模/要接的机会则直接进对应 Step。

## 完成度锚点（本流 1-10）
1 只觉得"组织不行" · 3 难度-强度判定 · 5 关系与容纳度诊断 · 7 信息环境修复方案 · 9 阶段要点对齐 · 10 写入作战地图

## Step 1：你的痛点（3 选项决策点）
```
✅ 进入组织诊断流。完成度：1/10
管理讲规则，组织讲人。机会最终由组织承接。

【你的痛点 — 3 选项】

★ A. 机会在眼前，组织接不住
   完整度：9/10 · 产出：难度-强度匹配诊断
   理由：先判断这事要靠规则、靠利益还是靠信念。

  B. 核心团队关系紧张/貌合神离
   完整度：8/10 · 产出：关系四阶段定位 + 整合动作
   理由：冲突是必经站，问题是卡住不动。

  C. 我总是最后一个知道坏消息
   完整度：8/10 · 产出：信息环境修复方案
   理由：决定质量取决于信息环境。

→ 我的推荐：按痛点选
回 A/B/C。
```

## Step 2：难度-强度匹配
```
✅ 完成度：1/10 → 3/10
两个判断（一次一个）：
1. 你要接的这个机会，靠共同规则就够，还是必须有共同利益，甚至共同信念？
2. 你现在的组织强度在哪一档？差几档？
```
展开读 references/org-capacity.md「框架」。

## Step 3：关系与容纳度诊断（3 选项决策点）
```
✅ 完成度：3/10 → 5/10
[逐段核心关系定位：理想 / 冲突 / 整合 / 协同创作]

⚠️ 卡在冲突期的关系：
【怎么推进 — 3 选项】
★ A. 做整合：接受对方真实的样子，重定协作方式（9/10）——容纳而不是改造
  B. 重设共同利益再谈（8/10）——多数协作靠利益就够
  C. 换人（4/10 ⚠️）——冲突是必经站，见冲突就换人永远到不了协同
→ 我的推荐：A
回 A/B/C。
```
四阶段读 references/org-capacity.md「框架」；自检用其「Checklist」。

## Step 4：信息环境修复
```
✅ 完成度：5/10 → 7/10
体检三问：坏消息延迟多久？经过几层转述？非共识有没有通道？
逐个扭曲点定修法：数据直达 / 分桌讨论 / 低成本试错小路。
```
修法读 references/innovation-flywheel.md「怎么用」。

## Step 5：阶段要点对齐
```
✅ 完成度：7/10 → 9/10
按五阶段（家庭/部落/村庄/城市/国家）定位你的组织，核对：你的精力分配和该阶段要点匹配吗？
```
五阶段读 references/innovation-flywheel.md「框架」。

## 收尾（完成度 ≥9/10）
诊断 + 修复方案写入 plan 文件「流产出」节（对应 templates/growth-battle-map.md 第 4 节）。
```
✅ 组织诊断完成度：9/10
【下一步 — 3 选项】
★ A. 组织理顺了，去借外力上台阶 9/10 → 继续：借势流
  B. 回头把模式落地 8/10 → 继续：模式设计流
  C. 排完整增长路线 8/10 → 继续：增长路线流
→ 我的推荐：A
```
