# 模式设计流 — 产出：目标-要素匹配 + 核心增强回路 + 模式选型

## 输入
先查 plan 文件「已确认事实」：已有破局点/业务目标则直接进 Step 2。

## 完成度锚点（本流 1-10）
1 模式糊的 · 3 目标写清 · 5 要素盘点完 · 7 回路画出 · 9 模式选型+做重计划 · 10 回路画布写入作战地图

## Step 1：目标确认
```
✅ 进入模式设计流。完成度：1/10
第一问不是"做什么产品"，是"做这件事你真正的目标是什么"。
一句话写下你要的结果（别写愿景，写结果）。
```
等用户答。展开读 references/factor-matrix.md「框架」。

## Step 2：要素盘点（3 选项决策点）
```
✅ 完成度：1/10 → 3/10
[按目标倒推必须要素，逐类标注：有 / 可获得 / 拿不到]

⚠️ 关键要素拿不到时：
【你的选择 — 3 选项】
★ A. 降级目标，匹配现有要素（9/10）——要素定生死
  B. 列获取路径和时间表再推进（8/10）——可行但别自欺
  C. 目标不变硬干（2/10 ⚠️）——坚持错目标 = 慢性失血
→ 我的推荐：A 或 B
回 A/B/C。
```

## Step 3：核心增强回路设计
```
✅ 完成度：3/10 → 5/10
画你的增长发动机：结果怎么反过来增强起点？（≤4 节点闭环，我们一起画）
画完找刹车：哪些调节回路在拖增长？逐条定"拆/绕/接受"。
```
方法读 references/feedback-loops.md「框架」「怎么用」；用 templates/loop-canvas.md 记录。

## Step 4：模式选型（3 选项决策点）
```
✅ 完成度：5/10 → 7/10

【你的模式 — 3 选项】

★ A. 用户增长模式（产品内置传播/留存回路）
   完整度：9/10
   理由：成本低复利强——前提是产品有天然分享理由。

  B. 连接器起步 + 明确的做重路线
   完整度：8/10
   理由：轻、启动快，但必须规划把价值核心收进来，否则被平台击穿。

  C. 一步到位做整合/平台
   完整度：4/10  ⚠️
   为什么低：重投入高门槛，多数团队的资源撑不起。

→ 我的推荐：按资源禀赋选 A 或 B
回 A/B/C。
```
四种模式的命门读 references/growth-models.md「框架」。

## 收尾（完成度 ≥9/10）
目标-要素表 + 回路画布 + 模式选型写入 plan 文件「流产出」节（对应 templates/growth-battle-map.md 第 3 节）。
```
✅ 模式设计完成度：9/10
【下一步 — 3 选项】
★ A. 检查组织接不接得住这个模式 9/10 → 继续：组织诊断流
  B. 找杠杆放大这个模式 8/10 → 继续：借势流
  C. 排完整增长路线 8/10 → 继续：增长路线流
→ 我的推荐：A
```
