# 增长路线流 — 产出：增长作战地图（台阶 + 深度 + 广度 + 选浪 + 底牌）

## 输入
先查 plan 文件「已确认事实」：优先复用其他流的产出（定位/破局点/模式/组织/借势结论），缺哪块补哪块。

## 完成度锚点（本流 1-10）
1 没有全局图 · 3 台阶定位 · 5 深度动作定 · 7 广度与选浪定 · 9 底牌明确+地图成型 · 10 交付作战地图

## Step 1：台阶定位（3 选项决策点）
```
✅ 进入增长路线流。完成度：1/10
五级台阶各有各的上法：0→1 破局点；1→10 杠杆；10→100 资源放量；100→1000 分形；1000→10000 扛苦难。

我判断你在 [X 台阶]。

【确认 — 3 选项】
★ A. 对（9/10）——核对当前打法与台阶是否匹配
  B. 在上一级/下一级（7/10）——按规模与状态重新核对
  C. 跨在两级之间（6/10）——那就按低的那级打，别抢跑
→ 我的推荐：如实定位，抢跑比落后更危险
回 A/B/C。
```
五台阶读 references/expedition.md「框架」。

## Step 2：用户深度（3 选项决策点）
```
✅ 完成度：3/10 → 5/10
你的用户是流量还是共同体？（复购、转介绍、危机时是否站你）

【深度策略 — 3 选项】
★ A. 设计信用与责任的沉淀动作（会员体系/深度服务/社群共建）（9/10）
  B. 先做好复购基本盘（8/10）
  C. 继续买量冲规模（4/10 ⚠️）——浅关系来得快去得也快
→ 我的推荐：A
回 A/B/C。
```
展开读 references/expedition.md「框架」。

## Step 3：广度与选浪
```
✅ 完成度：5/10 → 7/10
两个判断（一次一个）：
1. 广度：现有模式向下一个市场复制的条件齐了吗？组织准备好被重塑了吗？
2. 选浪：你的品类此刻在哪一浪（货/流量/数据）？你在为下一浪积累数据资产吗？
```
展开读 references/expedition.md「怎么用」。

## Step 4：增长底牌
```
✅ 完成度：7/10 → 9/10
最后一问：写下命运拿不走的那张牌——你的使命与核心能力。
它决定你敢走多远、在最难的台阶上撑不撑得住。
```
