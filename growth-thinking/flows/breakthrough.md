# 破局点流 — 产出：验证过的破局点 / 爆品三要素方案 + 基因匹配结论

## 输入
先查 plan 文件「已确认事实」：已有玩家定位与业务描述则直接进对应分支。

## 完成度锚点（本流 1-10）
1 只有想法 · 3 候选收敛完 · 5 破局点三特征过检 · 7 爆品三要素打分完 · 9 基因滤网过 + 方案成型 · 10 写入作战地图

## Step 1：你的处境（3 选项决策点）
```
✅ 进入破局点流。完成度：1/10

【你的处境 — 3 选项】

★ A. 机会太多/太少，先帮我把候选理出来
   完整度：9/10 · 产出：发散-收敛后的 1-2 个候选
   理由：机会不是等来的，是先放开列再狠心砍出来的。

  B. 有明确候选，验证它是不是真破局点
   完整度：9/10 · 产出：三特征检验结论
   理由：直接进检验，效率最高。

  C. 想做爆品，怎么判断成不成
   完整度：8/10 · 产出：三要素打分 + 补短板方案
   理由：爆品是三要素共振，不是灵感。

→ 我的推荐：按处境选
回 A/B/C。
```

## Step 2：发散与收敛（选 A 时）
```
✅ 完成度：1/10 → 3/10
先发散：三个来源各列 3 个候选（限制性条件的松动 / 用户的抱怨 / 你的独有禀赋）。
列完再收敛，砍的时候我陪你一条条过。
```
准则读 references/diverge-converge.md「怎么用」。

## Step 3：破局点三特征检验（3 选项决策点）
```
✅ 完成度：3/10 → 5/10
逐项检验：相对广谱？高频？体验可控？

⚠️ 有特征不过时：
【你的选择 — 3 选项】
★ A. 给它加频/收窄体验后再检（9/10）——先修再判，别硬上
  B. 换下一个候选（8/10）
  C. 特征不齐也硬做（2/10 ⚠️）——低频入口带不动任何东西
→ 我的推荐：A 或 B
回 A/B/C。
```
检验方法读 references/breakthrough-point.md「框架」「怎么用」。

## Step 4：爆品三要素 + 基因滤网
```
✅ 完成度：5/10 → 7/10
爆品三要素各打分（0-10）：供应链升级 × 品类空缺 × 新流量。
打完再过最后一道滤网：这个机会和你的基因（团队真正擅长的）匹配吗？
```
三要素读 references/hit-product.md「框架」；基因与周期读 references/gene-cycle.md「框架」。
