# 要素与模式选择 — 一句话定位：目标不同，该组装的要素就完全不同

## 框架

同一个品类可以长出完全不同的生意——差别不在产品，在**目标与要素的组合**。同样是开一家咖啡店：想赚房租差价的、想做连锁品牌的、想做流量入口的，三者要组装的要素（选址逻辑、供应链、资金结构、人才、数据能力）完全不同，命运也完全不同。

**模式设计的第一问不是"做什么产品"，而是"做这件事你真正的目标是什么"**。目标定了，才知道要凑齐哪些要素；要素凑不齐，目标就要降级或换路。

要素清单（按类盘点）：
- 资金结构（自有/融资/现金流型）
- 供应链与交付能力
- 流量与渠道
- 人才与组织能力
- 数据与技术
- 牌照/资质/关系等结构性资源

## 怎么用

1. 写下你的真实目标（一句话，别写愿景，写你想要的结果）
2. 倒推：达成这个目标**必须**有哪些要素？逐类列出
3. 对照现状：每个必须要素标记 有/可获得/拿不到
4. 决策：拿不到关键要素 → 换目标或换模式；能拿到 → 列获取路径
5. 判断题：你现在的日常动作，是在为这个目标补要素，还是在惯性做事？

## Checklist

- [ ] 目标是一句可验证的话，不是口号
- [ ] 必须要素清单齐全且逐项标注了可得性
- [ ] 模式与目标匹配（没有"想做品牌却按流量生意配要素"的错位）
- [ ] 每个缺口要素有获取路径和时间表

## 反模式

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 从"我想做 X 产品"出发 | 产品相同、目标不同 = 完全不同的生意 | 从目标出发倒推要素 |
| 用别人的模式套自己的要素 | 你没有他的要素组合 | 按自己的牌设计打法 |
| 目标坚定但要素永远凑不齐 | 坚持错的目标 = 慢性失血 | 要素定生死，及时换路 |
