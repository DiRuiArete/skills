# 信息环境、创新机制与组织五阶段 — 一句话定位：权力的本质是持续做对决定，而决定质量取决于信息环境

## 框架

**权力的两层**：表面看，权力由三样东西构成——信息的流向、利益的分配、资源的调度；往深处看，权力来自**一次次把决定做对所累积的信任**。而决定质量的命门是**决策者的信息环境**——信息被层层过滤和美化的组织，老板的每个决定都建立在失真数据上。

**创新飞轮**：持续出爆品的组织，靠的不只是算法或人才，而是**刻意压低创新阻力**——搭建高透明度的信息环境，让信息不因层级而扭曲，让新想法能被看见、被讨论、被快速试。透明信息环境 → 判断更准 → 试错更快 → 爆品概率更高 → 吸引更强的人 → 环境更透明，飞轮转起来。

**组织成长五阶段**（规模变化 → 创始人管理要点变化）：

| 阶段 | 规模感 | 创始人在管什么 |
|---|---|---|
| 家庭 | 几个人 | 靠自己干活；管人靠缘分 |
| 部落 | 十几到几十人 | 管战斗力——不能打就不能活 |
| 村庄 | 上百人 | 管资源、规则、节奏 |
| 城市 | 上千人 | 搭基础设施给全员赋能，靠秩序守住发展 |
| 国家 | 数千人以上 | 战略与文化 |

不变的一条：组织永远是人的组织；再大的公司也由一个个小团队构成。

## 怎么用

1. 信息环境体检：你听到的坏消息，平均延迟多久？经过几层转述？
2. 列出信息扭曲点（谁在过滤？为什么过滤？），逐个拆（数据直达/越级可见/匿名通道）
3. 给新想法设一条不经层层审批的试错小路
4. 阶段定位：按五阶段表判断你的组织在哪一站，检查你的精力分配是否匹配该站要点
5. 判断题：你上一个错误决定，是判断力问题，还是信息环境问题？

## Checklist

- [ ] 坏消息能在 24 小时内直达决策者
- [ ] 关键数据全员（或大范围）可见，不靠汇报转述
- [ ] 新想法有低成本试错通道
- [ ] 创始人精力分配与组织阶段匹配（城市阶段还在亲自管人 = 错位）

## 反模式

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 把权力理解为"拍板权" | 拍板不准，权力就在流失 | 把权力理解为决定质量 |
| 用保密文化管理信息 | 信息不对称最先坑死决策者自己 | 默认透明，例外保密 |
| 规模变了管法不变 | 家庭式管法带不了村庄 | 按五阶段切换要点 |
| 创新靠老板拍脑袋 | 单点判断撑不起持续创新 | 修信息环境，让创新涌现 |
