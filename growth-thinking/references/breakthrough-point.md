# 破局点 — 一句话定位：从 0 到 1 靠一个能撬开局面的点，而不是一张大蓝图

## 框架

破局点 = 你切入市场的第一个动作选点。选对了，后面的业务能被它带起来；选错了，再多资源也推不动。

**破局点的三个特征**（三者同时满足）：

| 特征 | 含义 | 判断问题 |
|---|---|---|
| 相对广谱 | 尽量多的人需要——人群扩展比频率扩展更难 | 这个服务的潜在人群够宽吗？ |
| 高频 | 高频业务能带动低频业务，反过来不行 | 用户多久用一次？能不能再高频？ |
| 体验可控 | 你能稳定兑现承诺的体验 | 关键体验环节在不在你手里？ |

**高频打低频**：用户频繁打开你，顺手就会用你的低频服务；靠低频入口去带高频业务，几乎不可能。经典史实：外卖这类日频入口带动了订酒店这类低频交易，反超了以机票为主入口的老玩家。

## 怎么用

1. 列出你业务里所有候选切入点
2. 逐个过三特征表（广谱 / 高频 / 体验可控），三项全 yes 的进入候选
3. 若无一全过：看能不能给某个候选**加频**（增加使用理由）或**收窄体验**（把不可控环节砍掉）
4. 选定后，把全部资源集中在这个点上打透，再谈延展
5. 判断题：你的破局点被打透后，下一个业务能被它自然带出来吗？

## Checklist

- [ ] 我的破局点三特征全部通过
- [ ] 我说得清它未来能带动哪些低频业务
- [ ] 破局期资源没有分散到第二个点
- [ ] 关键体验环节都在自己掌控内

## 反模式

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 用大而全的蓝图启动 | 0→1 阶段没有资源同时打多点 | 一个破局点打透 |
| 选低频高客单做入口 | 低频带不动任何东西 | 高频做入口，低频做变现 |
| 破局点体验依赖第三方 | 体验不可控 = 口碑不可控 | 关键环节收进自己手里 |
| 破局点刚见效就急着铺开 | 点还没打透，带不动面 | 打透再延展 |
