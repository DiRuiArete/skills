# 杠杆、共生与利益相关人地图 — 一句话定位：普通人的增长靠借力，借力有三件套

## 框架

### 1. 战略支点与杠杆
撬动超出自身体量的成果，需要**支点**（你立足的那个不可动摇的点：一项过硬能力、一份信任、一块根据地）和**杠杆**（放大器：资本、平台、品牌、关系、时代红利）。

拉开人与人差距的四种状态：没有支点；有支点但不肯用杠杆（连"吃亏"这种最朴素的杠杆都不用——短期让利换长期信任与机会）；杠杆臂太短（问题一解决就失去斗志，撬一下就停）；有杠杆没**准星**（多种杠杆形不成合力，无法成为时间的朋友）。

### 2. 共生
夹缝求生的正解不是硬刚，是**让渡部分自我，换取共享资源**：接入比你强的系统，让自己成为它生态里不可缺的一环——用局部自主权换生存空间与养分。

### 3. 结盟与利益相关人地图
长期的事必须让**对你影响力大的人在其中有长期利益**。利益相关人地图 = 把这件事牵涉的所有角色摆上桌：每个人的位置、他要什么、他能给什么、他可能从哪里伤到你（风险）、你能从哪里借到力（抓手）。

## 怎么用

1. 写下你的支点：哪个点是你确定站得住的？（站不住先补支点）
2. 盘杠杆：可用的放大器有哪些？给每个标注"启动成本 / 放大倍数"
3. 校准星：这些杠杆共同指向哪个目标？指不到一起的先收起来
4. 画利益相关人地图：列全角色 → 标位置/诉求/风险/抓手 → 给影响力最大的 2-3 人设计长期利益
5. 共生检查：有没有一个比你强的系统值得接入？接入要让渡什么？换回什么？
6. 判断题：你现在的增长，有多少来自借力，多少来自硬扛？

## Checklist

- [ ] 支点经得起压力测试（失去它业务是否崩塌）
- [ ] 每个在用的杠杆都指向同一个准星
- [ ] 影响力最大的相关人有明确的长期利益
- [ ] 共生关系里，我方的不可替代性在上升而不是下降

## 反模式

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 没支点先玩杠杆 | 放大器会同时放大坍塌 | 先立支点再上杠杆 |
| 不肯吃亏 | 拒绝了最便宜的信任杠杆 | 用短期让利换长期位置 |
| 杠杆各撬各的 | 无合力，成不了时间的朋友 | 定准星再配杠杆 |
| 共生中死守全部自主权 | 夹缝里硬刚 = 被碾 | 让渡换资源，保住核心 |
| 结盟只谈感情不谈利益 | 长期的事感情撑不住 | 用长期利益锁定关键角色 |
