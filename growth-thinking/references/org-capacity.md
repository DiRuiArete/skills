# 组织与人际容纳度 — 一句话定位：管理讲规则，组织讲人；机会最终由组织承接

## 框架

**组织 ≠ 管理。** 管理研究规则，组织研究怎么把人连接成一个整体。人不是机器：有情感、有恐惧，每个人的判断汇成组织的智慧，每个人的协同汇成组织的行动。强者通过组织行使意志，弱者通过组织获得安全——没人真的想当孤单个体。

**任务难度决定组织强度**：有的事靠共同规则就够；有的事没有共同利益就推不动；最难的事要靠共同信念。接多大的机会，先问组织强度够不够。

**建立关系的四个阶段**（组织由关系构成）：

| 阶段 | 发生什么 | 过关要点 |
|---|---|---|
| 理想 | 彼此投射美好想象 | 别把蜜月当实力 |
| 冲突 | 差异暴露，摩擦不断 | 冲突是必经站，不是散伙信号 |
| 整合 | 接受彼此真实的样子，重定协作方式 | 关键是**容纳**而不是改造对方 |
| 协同创作 | 一起做出单独谁都做不出的东西 | 组织真正成型的标志 |

**人际容纳度**：建组织的天花板，是创始人能真正容纳多少种和自己不一样的人。容纳度低的人只能带出复制自己的小团队。

## 怎么用

1. 给你要接的机会定难度：靠规则 / 靠利益 / 靠信念？
2. 对照现状：现在的组织强度在哪一档？差几档？
3. 盘点核心关系：每段关键合作关系处在四阶段的哪一站？卡在冲突期的怎么推进到整合？
4. 自检容纳度：团队里有几个"和你不一样但被你重用"的人？
5. 判断题：你最近一次重大分歧，是被容纳整合了，还是被权力压下去了？

## Checklist

- [ ] 机会难度和组织强度做过匹配判断
- [ ] 核心关系都过了冲突期进入整合（没有假性和谐）
- [ ] 团队里存在被重用的异质视角
- [ ] 共同利益设计覆盖了关键角色（不只靠感情）

## 反模式

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 用管理制度解决组织问题 | 规则管不了人心和协同 | 先修关系与利益，再上规则 |
| 冲突一出现就换人 | 冲突是整合的必经站 | 穿过冲突做整合 |
| 只招"和我像"的人 | 容纳度低 = 组织上限低 | 刻意保留异质成员 |
| 拿信念要求所有人 | 多数协作靠利益就够 | 按任务难度配强度 |
