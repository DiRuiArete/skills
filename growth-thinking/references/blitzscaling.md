# 风口与闪电式扩张 — 一句话定位：踩中风口就全速野蛮生长，风停之前回归秩序

## 框架

**风口判断**：真风口 = 市场出现短暂"净空"（需求爆发而供给和监管都没跟上）。概率极低，可遇不可求——但一旦确认踩中，常规打法就是错的。

**闪电式扩张**：风口期唯一目标是速度——用不计效率的速度抢占地盘，因为净空窗口一关，格局就定了。

**作战形态的演进**（随战果扩大与净空关闭而切换）：

| 形态 | 特征 | 适用期 |
|---|---|---|
| 海盗 | 无秩序、抢地盘、快过一切 | 净空期 |
| 海军陆战队 | 有组织的抢滩，边打边立规矩 | 净空收窄 |
| 军队 | 正规化作战、体系化补给 | 格局初定 |
| 警察 | 维护秩序、精细运营 | 市场成熟 |

野蛮终究要回归文明——但顺序不能反：用当警察的习惯去当海盗（把成熟期的流程与合规习惯带进净空期），会被更野的对手直接冲垮；反过来，风停了还在当海盗，会被秩序清算。

**跨越周期的姿态**：周期不是靠临场反应解决的——怕不做动作，也怕乱做动作；正解是**长期、持续地为跨越做准备**（现金储备、第二曲线布局、组织弹性）。

## 怎么用

1. 风口验证：需求是否爆发？供给是否短缺？窗口大概多久？（三问都答得出才算风口）
2. 确认风口 → 切换目标函数：从"利润/效率"切到"速度/占地"，并明说给团队
3. 设定形态切换信号：什么指标出现就从海盗切陆战队、切军队？（提前定，别靠感觉）
4. 非风口期 → 老实回到破局点与回路打法，不要自我催眠"这就是风口"
5. 判断题：你现在的作战形态，和市场所处阶段匹配吗？

## Checklist

- [ ] 风口判断有需求/供给/窗口三方面依据
- [ ] 风口期的烧钱有上限和里程碑（不是无限烧）
- [ ] 形态切换信号提前写下来了
- [ ] 为下一个周期的准备动作一直在做（不是等危机才动）

## 反模式

| 错误做法 | 为什么错 | 正确做法 |
|---|---|---|
| 把普通增长当风口 all-in | 没有净空，烧钱换不来格局 | 三问验证再切模式 |
| 风口期追求精细效率 | 慢一步地盘就是别人的 | 净空期速度优先 |
| 风停了还在野蛮扩张 | 秩序期会清算无序者 | 按信号切回正规打法 |
| 周期问题临场抱佛脚 | 周期只认长期准备 | 持续备粮备曲线 |
