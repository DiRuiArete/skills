# 个人战略流 — 产出：个人点线面体定位 + 能力圈 + 驱动类型 + 选择结论

## 输入
先查 plan 文件「已确认事实」：先收一句话：你在纠结什么选择（选赛道/跳槽/要不要坚持现在的事）？

## 完成度锚点（本流 1-10）
1 只有纠结 · 3 点线面体定位清 · 5 面与体的势能判断完 · 7 能力圈+存在感对齐 · 9 结论成型 · 10 行动计划落地

## Step 1：把选择翻译成点线面体（3 选项决策点）
```
✅ 进入个人战略流。完成度：1/10
你的岗位/项目是一个点。先看清它附着的线、面、体。

【先判断什么 — 3 选项】

★ A. 我现在的点附着在什么面上？面在涨还是缩？
   完整度：9/10
   理由：个体的命运差异主要来自面和体的势能，不是点上的勤奋。

  B. 直接比较两个 offer/选项的当下条件
   完整度：4/10  ⚠️
   为什么低：比当下条件是在比点——三年后回头看，面的走势碾压一切当下差异。

  C. 问身边人的意见
   完整度：3/10  ⚠️
   为什么低：多数建议来自对方的角色立场，不是你的面。

→ 我的推荐：A
回 A/B/C。
```
框架读 references/dian-xian-mian-ti.md「框架」（个人版用法在「怎么用」）。

## Step 2：势能判断
```
✅ 完成度：3/10 → 5/10
对每个候选选项回答（一次一个）：
1. 它所在的面，未来 3-5 年是扩张还是收缩？
2. 你在这个面上能借到的势能是什么（平台、人群、技术红利）？
3. 最差情况下，这条线还能把你带到哪？
```

## Step 3：能力圈与存在感对齐
```
✅ 完成度：5/10 → 7/10
两个内层问题：
1. 这个选择在不在你的能力圈内？出圈的部分你有没有补课路径？
2. 它符合你想成为的存在吗？（战略存在层——你希望别人因为什么需要你？）
```
五层次的个人评估读 references/five-layers.md「框架」。

## Step 4：驱动类型判断（3 选项决策点）
```
✅ 完成度：7/10 → 8/10
你是自我驱动还是自律驱动？

【判断 — 3 选项】
★ A. 自我型（靠兴奋感驱动，讨厌被约束）→ 选创造性、不确定性高的事（9/10）
  B. 自律型（靠秩序感驱动，擅长长期执行）→ 选确定性强、复利型的事（9/10）
  C. 不确定 → 用"什么事让你不知疲倦"自测（7/10）
→ 我的推荐：如实归类——选和天性拧着的路，每天都在内耗
回 A/B/C。
```
两类人格读 references/roles.md「框架」。

## Step 5：人生逻辑收束
```
✅ 完成度：8/10 → 9/10
最后用一个问题收束：抛开收益最大化，你想通过这件事成为什么样的存在？
商业逻辑帮你算账，人生逻辑帮你定方向——长期驱动力只能来自后者。
```
展开读 references/worldview.md「框架」。

定位 + 判断 + 结论 + 30 天行动写入 plan 文件「流产出」节。

→ 我的推荐：A
