# 创新破局流 — 产出：价值公式算账 + 新要素组合 + 模式选择 + 价值网检查

## 输入
先查 plan 文件「已确认事实」：已有机会画布/竞争格局描述则直接进 Step 2。

## 完成度锚点（本流 1-10）
1 只有焦虑 · 3 价值公式算完 · 5 新要素盘点完 · 7 模式选定 · 9 价值网检查完 · 10 创新画布成型

## Step 1：你的处境（3 选项决策点）
```
✅ 进入创新破局流。完成度：1/10

【你的处境 — 3 选项】

★ A. 挑战者：想从在位者手里抢用户
   完整度：9/10 · 产出：价值公式算账 + 差异化路径
   理由：先算清楚用户凭什么换你——不算账的挑战是送死。

  B. 找新品类/新物种机会
   完整度：8/10 · 产出：交叉视角 + 新要素组合
   理由：增量空间大，但要验证要素是否真的"新"。

  C. 在位者：怕被颠覆
   完整度：8/10 · 产出：价值网自检 + 应对动作
   理由：被颠覆的不是产品，是你的价值网。

→ 我的推荐：按处境选
回 A/B/C。
```

## Step 2：用户价值公式算账（3 选项决策点）
```
✅ 完成度：1/10 → 3/10
用户价值 = 新体验 − 旧体验 − 替换成本。逐项填数（我一项项问）。

⚠️ 算出来 ≤0 或勉强为正时：

【你的策略 — 3 选项】
★ A. 把新体验做到碾压级再出手（9/10）——微弱优势覆盖不了替换成本
  B. 主攻降替换成本（迁移工具/兼容/零学习成本）（8/10）
  C. 换个没有旧体验的新市场打（8/10）——无旧体验 = 公式里少减一项
→ 我的推荐：按你的资源禀赋选
回 A/B/C。
```
公式与两方含义读 references/value-formula.md「框架」「怎么用」。

## Step 3：交叉视角 + 新要素盘点
```
✅ 完成度：3/10 → 5/10
两个动作（一次一个）：
1. 交叉视角：哪个别的领域已经把"你要的体验"做成熟了？能不能移植过来？
2. 新要素盘点：此刻有哪些新技术/新链路/新人群可以注入你的品类？
```
方法读 references/cross-innovation.md「怎么用」；对照其「Checklist」。

## Step 4：三级火箭判断（3 选项决策点）
```
✅ 完成度：5/10 → 7/10
如果你的模式涉及"先免费圈流量再变现"，先做三级火箭适用性判断：

【判断 — 3 选项】
★ A. 三前提都满足（一级真高频 / 有巨大势能资源 / 有逐级转化操盘力）→ 可用（9/10）
  B. 部分满足 → 降级为两级或单级模式（7/10）
  C. 都不满足还硬上 → 停（2/10 ⚠️）——烧完流量钱找不到第二级是经典死法
→ 我的推荐：如实自评，不要为了模式性感硬凑前提
回 A/B/C。
```
展开读 references/three-stage-rocket.md「框架」「反模式」。

## Step 5：价值网检查
```
✅ 完成度：7/10 → 9/10
最后一道检查（挑战者和在位者都要做）：
1. 你现在的客户、供应链、考核指标把你锁在哪张价值网里？
2. 你要做的创新是延续性的还是颠覆性的？
3. 如果是颠覆性的——现有价值网会不会"理性地"杀死它？要不要独立小团队做？
```
展开读 references/disruption.md「框架」「怎么用」。

```
  B. 回体验设计落地新模式 8/10 → 继续：体验设计流
  C. 输出创新方案文档 8/10
→ 我的推荐：A
```
