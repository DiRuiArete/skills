# 机会判断流 — 产出：机会画布（点线面体定位 + 势能 + 切入点 + 画像与场景验证）

## 输入
先查 plan 文件「已确认事实」：已有想法/赛道描述则复述确认后直接进 Step 2。否则先收：1）你的机会/想法一句话；2）它附着在哪个行业/平台上？

## 完成度锚点（本流 1-10）
1 只有想法 · 3 点线面体定位清晰 · 5 势能验证完 · 7 切入点（痛/痒/爽）锁定 · 9 画像+场景验证完 · 10 机会画布成型

## Step 1：点线面体定位（3 选项决策点）
```
✅ 进入机会判断流。完成度：1/10

你现在描述的是一个"点"。判断机会先看它附着的面和体。

【先做什么 — 3 选项】

★ A. 先判断面和体（这个点长在哪个面上？面在涨还是在缩？）
   完整度：9/10
   理由：点的努力决定下限，面和体的势能决定上限。面选错，点再优秀也没用。

  B. 直接打磨这个点（产品细节/功能）
   完整度：3/10  ⚠️
   为什么低：只在点上使劲是最常见的机会误判——把战术勤奋当战略。

  C. 先看竞品在做什么
   完整度：6/10
   理由：有参考价值，但竞品动作不能替代你对面的独立判断。

→ 我的推荐：A
回 A/B/C。
```
框架展开读 references/dian-xian-mian-ti.md「框架」。

## Step 2：势能验证
```
✅ 完成度：3/10 → 5/10
回答三个判断题（我一次问一个）：
1. 这个面未来 3-5 年是扩张还是收缩？驱动力是什么？
2. 面下面的体（宏观经济/人口/技术周期）是托举还是拖累？
3. 你是在赚"面上涨"的钱，还是在赚辛苦钱？
```
判断步骤读 references/dian-xian-mian-ti.md「怎么用」；答完对照其「Checklist」。

## Step 3：切入点定性（3 选项决策点）
```
✅ 完成度：5/10 → 7/10
面选定了，现在定这个机会打用户的什么。

【你的切入点 — 3 选项】

★ A. 痛点切入（用户在恐惧/怕失去什么）
   完整度：9/10
   理由：痛点驱动付费意愿最强、最刚性。

  B. 爽点切入（即时满足，抓住就上瘾）
   完整度：8/10
   理由：留存引擎强，但要有确定性兑现能力。

  C. 痒点切入（理想自我的投射）
   完整度：7/10
   理由：适合内容/品牌类机会，变现链路更长。

→ 我的推荐：按你的机会属性选（三类都成立，怕的是哪类都不占）
回 A/B/C。
```
三类机理与判别读 references/pain-itch-pleasure.md「框架」；场景规划读其「怎么用」。

## Step 4：画像与场景验证
```
✅ 完成度：7/10 → 9/10
最后两道验证：
1. 画像验证：你的第一只羊是谁？被服务爽了吗？头羊在哪？狼（付费方）是谁？
2. 场景验证：用户在什么时间、什么空间、被什么情绪触发来用你？
```
两套画像读 references/personas.md「框架」；验证清单用其「Checklist」。

## 收尾（完成度 ≥9/10）
按 templates/opportunity-canvas.md 填机会画布，写入 plan 文件「流产出」节。
```
✅ 机会判断完成度：9/10
【下一步 — 3 选项】
★ A. 深挖目标用户（情绪/防御/分类）9/10 → 继续：用户理解流
  B. 直接设计体验 7/10 → 继续：体验设计流
  C. 先想清创新模式与竞争 8/10 → 继续：创新破局流
→ 我的推荐：A
```
