# 用户画像卡

> 用法：一个产品一张卡。生态角色三行必填；羊种占比合计 100%。

## 生态角色

| 角色 | 具体是谁 | 现状证据 | 维护动作 |
| --- | --- | --- | --- |
| 第一只羊（种子用户） | | 他爽到的瞬间是什么？ | |
| 头羊（自组织节点） | | 数量：____ 只 | |
| 狼（付钱方） | | 收狼钱 / 剪羊毛 | |

## 羊种占比

| 羊种 | 特征速记 | 占比 | 我给他的核心价值 |
| --- | --- | --- | --- |
| 大明 | 目标明确，比价比效率，无忠诚 | % | |
| 笨笨 | 有方向没答案，爱逛易被激发 | % | |
| 小闲 | 不想消费，只想消磨时间 | % | |

## 策略对齐

- 主力羊种：____
- 他打开产品那一刻的心理预期：____
- 与预期对齐的核心动线：____
- 明确不做的事（防预期断裂）：____

## 草地体检

| 问题 | 回答 |
| --- | --- |

## 红线自检

- [ ] 没把补贴撑住的留存当成第一只羊活了
- [ ] 头羊数量与网络效应判断一致
- [ ] 小闲流量没被硬导向交易
- [ ] 笨笨的逛没被过度过滤成搜索
