# 体验自查表

> 用法：复制本表，对照一个具体产品（或一次服务）填写。顺序：先过五层，再标峰终，最后列触点。打分 1-5：1=明显短板，3=达标，5=显著优势。

## 一、五层次逐层打分

| 层次 | 关键自问 | 现状描述 | 打分 | 改进动作 |
|---|---|---|---|---|
| 战略存在层 | 用户凭什么持续依赖我们？我们自己图什么？ | | | |
| 能力圈 | 哪些确定性必须亲手交付？明确不做什么？ | | | |
| 资源结构层 | 钱 / 人 / 内容 / 势能撑得起能力圈吗？ | | | |
| 角色框架层 | 信息组织与服务角色，把实力顺畅递到用户手上了吗？ | | | |
| 感知层 | 第一印象配得上内核吗？ | | | |

> 指引：自上而下填。若外层高分、内层低分（如感知 5 分、战略 2 分），优先补内层——外壳救不了内伤。
