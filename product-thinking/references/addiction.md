# 上瘾机制 — 用「完成动作就有满足」的确定性闭环留住用户，并守住它的伦理边界

## 框架

**激励的原理**：向用户明示一条规则——做出预定动作就能获得满足——并且每次兑现。
压力在过程中积累、在动作完成的瞬间释放，叠加确定兑现的回报，形成让人反复回来的循环。

**外在激励**：奖金、补贴、红包、排名等外部报酬。
- 见效快，是短期改变行为最锋利的工具。
- 代价：用户会把它计入预期。一旦撤掉，体感不是「回到原点」而是「被夺走」——确定性的丧失本身就是伤害。

**内在激励**：胜任感、看得见的成长、成就感、同好的认同。
- 慢热但可持续，是让人持续深入、把事做透的动力。
- 它并非全靠自发：环境的激发、同侪的围观与认同，会成倍放大内在激励。

**激励三性**：即时（动作完成立刻反馈）、可预期（规则事先透明）、确定（说了给就必须给）。缺任何一条，效力都大打折扣。

**成瘾回路**：触发 → 行动 → 奖励 → 投入。
- 触发：内部渴求或外部提醒，把需求拉起来。
- 行动：门槛越低越好——操作、时间、设备、思考四类门槛都可削。
- 奖励：固定奖励给确定感，再叠少量可变奖励制造意外爽点。
- 投入：让用户存下数据、关系、声望等沉没价值，回路越转越紧。

**两个设计件**：
- 受激励点密度：成就节点要多而小、铺满全程，而不是憋一个年终大招。
- 获得能力匹配：奖励超出对方能力就等于没有奖励；先降门槛，再谈激励。

受激励点通常组织成成就体系：勋章、等级、称号这类符号本身不值钱，
值钱的是它见证的挑战与付出——符号只是给成就感一个可展示的锚。

**伦理边界**：激励系统是行为放大器。帮用户达成 TA 自己认同的目标，是产品力；
用可变奖励掏空用户的时间与钱包、不留真实价值，是透支信任。判断题：用户一年后回看这段投入，会感谢还是后悔？

## 怎么用

1. **定义核心动作**：你要强化的动作是什么？判断题：它对用户自身有独立于奖励的价值吗？
2. **选激励主线**：内在为主、外在为辅，还是外在冷启动、内在接棒？写明切换条件。
3. **铺受激励点**：把大目标切成高频小成就，让新手第一天就能拿到第一个。
4. **削四类门槛**：操作、时间、设备、思考，逐项问一遍：还能再降吗？
5. **设反馈**：即时、可预期、确定；可变奖励只叠在固定奖励之上，不替代它。
6. **谨慎动激励**：任何撤销、降档、改版都在打破确定性，必须有预告与过渡设计。
7. **过伦理审**：假设停掉激励一个月，用户手里还留下什么真实所得？

## Checklist

- [ ] 核心动作对用户有独立于奖励的真实价值
- [ ] 反馈在动作完成后立刻到达
- [ ] 激励规则事先可见、从不跳票
- [ ] 成就节点覆盖新手到高手全程
- [ ] 操作 / 时间 / 设备 / 思考四类门槛做过一轮削减
- [ ] 撤改激励有过渡方案与提前告知
- [ ] 通过「一年后回看」的伦理自问

## 反模式

- **错误**：外在激励断崖式撤销。
  **为何错**：打破已形成的确定性预期，用户体感是被剥夺，连内在动力一起受损。
  **正确**：设计之初就写好退坡路径；撤前预告、分级过渡。

- **错误**：憋大招，年底一次性重奖。
  **为何错**：受激励点过于稀疏，过程中长期无反馈，行为无从强化。
  **正确**：高频、小额、即时的激励节点铺满全程。

- **错误**：给能力不匹配的人上强激励。
  **为何错**：够不着的奖励形同虚设，还会制造挫败与怨气。
  **正确**：先降门槛或换目标人群，让奖励落在踮脚可及处。

- **错误**：用可变奖励填充空洞产品。
  **为何错**：短期数据好看，长期掏空信任，舆论与监管风险随之而来。
  **正确**：先保证动作本身的真实价值，再叠加回路。

## 案例速写

- 某国民级手游把操作压到两指三键、单局压到几分钟、全机型互通、每日任务代替规划——四类门槛同时削减，用户盘子随之数量级放大。
- 网约车平台早年的补贴混战，示范了外在激励短期改写出行习惯的力量，也示范了补贴退坡后的留存考验。
