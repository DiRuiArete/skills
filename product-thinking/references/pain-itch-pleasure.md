# 痛点·爽点·痒点 — 恐惧、即时满足、虚拟自我是仅有的三类切入点，且必须配上能触发情绪的场景才有流量

## 框架

### 三类机会的机理

| 类型 | 底层机制 | 判别信号 |
| --- | --- | --- |
| 痛点 | 恐惧：怕损失、怕出丑、怕危险 | 用户原话里出现"怕" |
| 爽点 | 被压着的需求零延迟兑现 | 一伸手就有，秒级闭环 |
| 痒点 | 虚拟自我：理想生活的投射 | 用户围观、模仿、晒 |

- **痛点不等于难受**。需求没被满足只是不舒服，构不成切入点；只有背后站着恐惧，用户才会立刻掏钱消灾。
- **爽点的命门在"即时"**。确定的需求 + 零等待的响应 = 爽；若兑现要绕远路、熬长周期（如自我实现），它撑不起产品——人性天然怠惰，没有恐惧追赶又没有即时反馈喂养，行为不会发生。
- **痒点不解决问题，它出售想象中的自己**。用户买的不是功能，是"用上它，我就部分过上了那种生活"。追剧的人反复讨论的从来不止剧情主线，而是角色的神情、穿搭、生活质感——支撑长期热度的正是这些投射物。

### 快速判别三问

依次问，最先答"是"的就是候选切入点：

1. 不做这件事，用户会怕吗？怕什么、怕到什么程度？→ 痛点
2. 做这件事，能让一个确定的欲望当场兑现吗？→ 爽点
3. 用上这个东西，用户离理想中的自己更近了吗？→ 痒点

三问全是"否"，说明手里只有一个"用户有点难受"的观察，还不构成机会。

### 场景：情绪的点火装置

- 场 = 时间 × 空间。用户能在这个时空里停留、消费，场才成立。
- 景 = 情景 + 互动。在停留的时空里点燃情绪，并让人群互相裹挟。
- 两者齐备才叫场景。只有屏幕与入口而无情绪触发，等于商品在货架上冷冷一摆，不会有流量。
- 推动人行动的是情绪，理智只负责往回拉。所以规划产品必须同步规划场景：用户在哪个时刻、被哪种情绪推着伸手拿你？
- 同一件商品换一个场景，消费行为可以天差地别；新场景的出现（如被切碎的通勤时间）本身就是新机会。

## 怎么用

1. **听动词**：收集用户原话。判断问题：他说的是"怕"（痛点）、"现在就要"（爽点），还是"好想成为"（痒点）？
2. **验恐惧**：把候选痛点翻译成一句"用户怕____"。判断问题：空格填不出具体恐惧，就降级为难受，弃用。
3. **测时延**：数一数从起念到被满足要几步、几分钟。判断问题：能否压缩到伸手即得？
4. **照镜子**：写出目标用户的理想自我形象。判断问题：产品让他离那个形象近了一步吗？他愿意晒出来吗？
5. **排场景**：列出产品被使用的具体时空。判断问题：那一刻他被什么情绪推着？谁在旁边裹挟他？
6. **选主攻**：三点可叠加，主打只能有一个。判断问题：团队对哪个点手感最准、感受最深？

## Checklist

- [ ] 切入点能填进"怕____ / ____立刻兑现 / 想成为____"三个句式之一
- [ ] 没有把"用户过得难受"直接当成痛点立项
- [ ] 爽点路径已压缩到即时兑现，不含长周期承诺
- [ ] 痒点对应一个具体的理想形象，而非泛泛的"变好"
- [ ] 每个核心功能都写明场景：时间、空间、触发的情绪
- [ ] 场景里有情绪触发与人群互动，不是只有触点
- [ ] 验证过换场景后的行为差异，没有拿错场景的流量硬转化
- [ ] 主攻点与团队手感匹配：选了最能持续做深的那一个

## 反模式

### 把难受当痛点
- 错误做法：看到一群人忙、累、被琐事困住，就立项"帮他们成为更好的自己"。
- 为什么错：既没有恐惧驱动，又给不了即时兑现，产品不痛不痒；自我提升是长跑，没人被它推着走。
- 正确做法：要么挖出这群人真正怕的事，要么把某个具体环节做到伸手即得。

### 承诺远期幸福
- 错误做法：产品价值要用户坚持数月才能兑现。
- 为什么错：寻求中的人要的是当下被接住，远期回报敌不过眼前怠惰。
- 正确做法：把大目标切成一连串即时反馈，每次使用都有一口甜。

### 拿功能清单打痒点
- 错误做法：用参数、性价比迎战靠形象走红的产品。
- 为什么错：痒点用户买的是理想生活的门票，参数表演算不动想象力。
- 正确做法：经营形象与生活方式叙事，让用户一晒就完成自我投射。

### 有入口没场景
- 错误做法：铺渠道、堆触点，认为入口多转化自然来。
- 为什么错：入口只是时空，情绪没被触发就没有行动，摆得再多也只是冷货架。
- 正确做法：为每个触点设计景——此刻他为何心动、谁在带节奏。

### 痛点万金油
- 错误做法：把一切走红都归因于"抓住了某个痛点"，立项材料言必称痛点。
- 为什么错：概念被用滥就失去判别力；大量走红产品靠的其实是痒点或爽点，误诊机制会抄错作业。
- 正确做法：用"怕 / 立刻 / 想成为"三问重新归因，对不同机制用不同打法。

## 案例速写

- 同样卖一顿饭：管饱只是功能；酣畅到出汗是爽点；帮怕胖的人控卡路里是痛点；摆盘美到必须先拍照发圈，是痒点。
- 同一套限量书：在社群的倒计时氛围里被一抢而空，转挂普通货架打对折却无人问津——差的不是货，是场里的景。
- 网红店主提前一周控体重、用十天拍一张"随手"街拍——粉丝成套下单买的不是衣服，是照片里那种生活。
