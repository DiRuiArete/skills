# 角色化生存 — 认清角色与真人，再决定为谁设计

## 框架

**角色化生存**：

- 日常照面的多半是角色，不是完整的人。职务、头衔、"好学生""好员工"，都是被训练出来的行为模板：制服在身，人按制度行事；制服脱下，才露出本人。
- 角色是训练的产物，配方五步：设定目标 → 用惩罚立起恐惧的边界 → 给出唯一正确动作 → 用奖励养成路径依赖 → 高频重复。
- 训练服务于管理效率，所以角色天然压抑天性。角色化生存是每个人的常态处境，但角色不等于真人。
- 集体人格：一群人被同一套观念反复灌输（同一种教育、企业文化、地域文化），会长出一致的行为预期与共同记忆，这就是集体人格。集体，就是角色的聚合体。
- 关键定律：人只有在足够压力下才进入角色；压力一撤，行为回落到天性与潜意识。

**教育是理想化工程**：

- 角色训练按社会的理想期望塑形，而天性并不长这样，模板与真人之间存在恒定落差。
- 推论：照理想模板推演用户，注定失真——书面上的"标准用户"在现实里是小概率事件。

**对产品设计的推论**：

- 面向个体：不能按角色预期设计。瘫在沙发上刷手机的人已卸下"经理""母亲"的壳，不会照角色说明书使用你的产品。
- 个体产品的合格线是"自然"：不识字的幼儿也能划开触屏，靠天性而非学习。
- 面向集体：若使用场景本身就角色化（办公协作、审批、教务），按角色设计反而正确。此时该研究的是这个集体的集体人格、共同记忆与规则体系。

**自我与自律，两种人格**：

- 自我的人：感受力强，能在众人已有结论处长出新观察；情绪外露、时间观念弱，关注"我喜欢什么"。
- 自律的人：逻辑与秩序感强，情绪稳定、守规则、容易进入角色，关注"什么是对的"。
- 驱动来源：靠愉悦驱动的人偏自我；靠恐惧驱动的人偏自律。两种驱动都能成就出色的人。
- 分工规律：创造要求对自身感受深度体察并释放出来，偏自我；控制与规模化要求服从规则、体谅他人，偏自律。
- 从零到一的产品创造多由自我人格扛旗；流程、品控、运营更适合自律人格。顶尖创造者常在协作中显得自私难处，这是同一枚硬币的两面。
- 自测：纠结"我该更自我还是更自律"，提出这个问题本身多半说明你偏自律；判别看驱动——你不计回报投入的那件事，靠的是快乐还是怕。
- 组织解法：成大事的人需要与自己相反的人格结成深度搭档——创造者身边要有守边界、兜交付的人。

## 怎么用

1. **先判定场景**：用户使用产品时，是顶着压力在扮演角色（上班、协作、被考核），还是独处放松？
   - 判断题：压力从哪来、够不够大？答不出压力来源，就按无角色处理。
2. **面向个体时**：把设计文档里每句"用户应该……"改写成"用户凭本能会……"。
   - 判断题：这条改写得出来吗？改不出来的功能，简化或砍掉。
3. **面向集体时**：先梳理角色结构，再按角色说明书设计流程与权限。
   - 判断题：谁下达、谁执行、谁考核？这个集体的共同语言和禁忌是什么？
4. **审用户研究**：把角色发言与真实行为分开记录。
   - 判断题：受访者当时处在哪个角色里？哪些话是角色要求他说的？
5. **配人**：自我配创造，自律配控制。
   - 判断题：这份工作要创造还是要控制？候选人靠愉悦驱动还是恐惧驱动？
6. **组队**：给核心创造者配互补搭档。
   - 判断题：谁来兜节奏、边界与交付？没有此人，创造力会烧穿组织。

## Checklist

- [ ] 明确写下产品面向"个体自然状态"还是"角色化场景"
- [ ] 设计文档中没有未经行为验证的"用户应该"
- [ ] 个体产品：新用户零培训即可走通核心路径
- [ ] 个体产品：文案与流程没有强迫用户扮演某个角色
- [ ] 集体产品：梳理过目标集体的集体人格、共同记忆与规则
- [ ] 用户研究里角色发言与真实行为分开记录
- [ ] 关键岗位的人格类型（自我/自律）与工作性质匹配
- [ ] 核心创造者身边配了自律型搭档

## 反模式

- **对放松状态的个体做角色化设计**（"她是母亲，所以会……"）→ 无压力时人不扮演角色，预期必然落空 → 按天性设计，验证"不教就会"。
- **给强角色化场景做"自由随性"设计** → 协作场景的价值恰恰来自角色的确定性 → 研究该集体的集体人格，按规则与流程设计。
- **用自律标准筛选创造者**（守时、稳定、服从优先）→ 系统性筛掉感受力，而创造正靠感受力 → 创造岗位容纳自我人格，用自律搭档补上控制。
- **把角色化预期强加给用户或伴侣**（"对方应该懂"）→ 对方没有义务照你的剧本行动 → 放下"应该"，观察并接纳真实的人。

## 案例速写

- 办公协作产品可以理直气壮地要求打卡、走审批，因为使用场景本身角色化；同一套逻辑搬进个人休闲产品，必然把用户劝退。
- 某社区团队复盘增长：面向"宝妈"角色设计的功能全数遇冷，数据里跑出来的高频行为是深夜刷短内容——无压力时刻，用户回到了天性。
