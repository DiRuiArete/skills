# 用户价值公式 — 用一道减法判断用户凭什么换你：新旧体验之差扣掉替换成本，净值不为正就别开战

## 框架

用户价值 =（新体验 − 旧体验）− 替换成本

| 变量 | 含义 | 常被忽略的部分 |
| --- | --- | --- |
| 新体验 | 你的产品带给用户的综合感受总分 | 价格也是体验的一部分 |
| 旧体验 | 用户现有解法的总分 | 竞品之外，土办法、人肉流程、「忍着不解决」都算 |
| 替换成本 | 从旧换到新要付出的全部代价 | 认知新品牌、找到并装上、重新学习、迁移数据、放弃旧账户里的积累、出问题找谁 |

三个推论：

- **对挑战者**：比的不是绝对分，而是差值扣掉替换成本后的净值。对成熟对手做两三成的局部优化，通常不够付替换成本——你自认更好，用户拿到手的是负数，视你为可有可无。只有碾压级的新体验，才有资格谈迁移。
- **对守成者**：用户在你身上的沉没投入——数据、关系链、习惯、已付费——就是护城河。体量大的一方还能反向收割：用户换到大平台近乎零成本，品牌已知、渠道现成、用法早被教育好；大厂可以后发慢磨，逐步蚕食小玩家。
- **对选战场**：旧体验趋近于零的市场里，60 分就是用户实打实拿到的 60 分。此时正确节奏是及格即上线、全速铺开，让先占下的用户习惯成为后来者要支付的替换成本；憋着打磨满分反而错失窗口。

什么时候该进新市场打「无旧体验」的仗：净值在存量市场算不正、同维度对手体量远大于你、而某个人群或场景还没有像样解法——三个信号凑齐，就离开存量、去增量。

## 怎么用

1. **给旧体验定价**：用户现在拿什么解决这个问题？综合值多少分？判断问题：我有没有把「没竞品」误当成「旧体验为零」？凑合方案也是旧体验。
2. **列替换成本清单**：认知、获取、学习、数据迁移、关系与积累、售后可得性，逐项写实。判断问题：如果产品免费送，用户会不会仍嫌麻烦不换？
3. **算净值**：新体验减去前两项。判断问题：结果是显著为正，还是勉强打平？打平等于没有。
4. **对体量**：同一维度里先比体量。判断问题：对手远大于我？放弃仰攻。体量相当？做好打持久消耗战的准备。我远大于对手？可以后发跟进碾压。
5. **换战场**：净值算不正时，找旧体验近零的人群、场景或地域。判断问题：那里是否真无像样解法，而我能最快铺开？

## Checklist

- [ ] 旧体验有具体对象和打分，不是「市场空白」四个字
- [ ] 替换成本逐项列过清单，含无形的习惯与积累
- [ ] 净值显著为正，且说得出碾压点在哪
- [ ] 同维度对手的体量摸过底，仰攻巨头的方案已否决
- [ ] 备选了至少一个旧体验近零的细分战场
- [ ] 零旧体验市场的节奏定为「及格即发布、速度优先」

## 反模式

### 「我比它好三成」就立项
- 错误做法：盯着体验差值立项，认定做得更好用户自然会来。
- 为什么错：差值要先扣掉替换成本，局部优化的净值常为负；没人为「略好」搬家。
- 正确做法：先列完替换成本清单再算净值，不显著为正就换方向。

### 轻视大厂后发
- 错误做法：认为自己先做出了好产品，大厂跟进也不怕。
- 为什么错：用户流向大厂几乎零替换成本，对方拿体量慢慢磨，能把先发优势磨光。
- 正确做法：避开与巨头同维度对打，去它够不着或看不上的增量市场建根据地。

### 空白市场憋大招
- 错误做法：在无人竞争的新市场里反复打磨，非满分不发布。
- 为什么错：零旧体验市场的壁垒来自先占速度，不来自完成度；窗口一过，你反而成了要付替换成本的一方。
- 正确做法：及格线即上线，用铺开速度换用户习惯，边跑边补。

### 把「没有竞品」当「没有旧体验」
- 错误做法：调研只看同类产品，看不到就宣布市场空白。
- 为什么错：用户的土办法、人肉流程甚至「不解决」都是旧体验，替换惰性照样收费。
- 正确做法：按用户真实现状给旧体验打分，再决定这仗值不值得打。

## 案例速写

- 办公软件史上，本土后来者以更低价格、七成功能挑战垄断者，用户算完替换账仍不搬家——综合略优不等于净值为正。
- 音乐软件混战时代，巨头凭渠道与版权优势后发入场，用户切换毫无成本，市场迅速一家独大——同维度竞争里体量就是胜负手。
- 一位安全软件出身的创业者放弃与老东家缠斗，转身出海做无人认真做过的手机清理工具——在旧体验为零的市场，及格分即可立足。
