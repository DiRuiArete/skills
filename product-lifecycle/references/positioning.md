# 找产品定位：差异化 × 增长 × 未满足需求

> 后来者最大的诱惑是"找一个更大众的定位让用户群更大一点"，结果是淹没在竞品里。本文给你一个三维度判断框架。

## 核心原则

定位 = 在三个维度上**同时**满足：

```
       差异化定位 ──┐
                    ├── 你的产品定位
       增长市场 ────┤
                    │
   未被满足的需求 ──┘
```

少任何一个维度都会让你的产品要么没特色（被竞品拍死）、要么市场太小（养不活）、要么被现有产品压死（差异化不实质）。

---

## 维度 1：差异化定位

### 反模式：用别人都在用的维度切市场

汽车行业惯用的市场切分维度：
- 按价格段（10万、20万、30万级）
- 按车型（轿车、SUV、MPV）
- 按用户标签（"专为现代精英打造"）

**问题**：这些维度大家都在用，你只是挤进已经拥挤的格子。而且用户标签往往是品牌方的一厢情愿——很多人并不愿被标签化。

### 破局法：找一个新维度，构造二维矩阵

理想汽车的破局：在"价格"之外，加了**"用户人生阶段"**作为新维度——

| 人生阶段 | 用车任务 |
|---|---|
| 刚工作的年轻人 | 通勤代步 |
| 成家有孩子（有娃家庭） | 全家出行、接送、应急 ← **此前无人旗帜鲜明地服务** |
| 事业有成 | 商务场合 |

新维度 + 价格 = 新二维矩阵 → 找到"无人区"。

### 给你的方法

1. 列出你的行业现有的市场切分维度
2. 问一个根本问题：**用户在不同的人生阶段 / 工作阶段 / 使用情境下，你的产品能帮他完成什么任务？**
3. 把答案作为新维度，画出二维矩阵
4. 找格子里没有竞品的位置——这就是你的差异化定位候选

## 维度 2：高速增长的市场

### 反直觉：不要选"现在最大的市场"

"最大市场"往往挤满竞品 + 还在萎缩。

理想汽车的反直觉判断：
- **15 万以下通勤车** — 市场最大 → **但在萎缩**（年轻人买车意愿下降：城市牌照难、停车难、网约车更划算）
- **20 万 + 家庭车** — 看起来小 → **但在高速增长**（二胎、家庭升级、代际换车）

### 给你的方法：双轨判断市场

| 看 | 你要问的问题 |
|---|---|
| 存量规模 | 现在多大？ |
| **增长趋势** | 三年后会变大还是变小？驱动力是什么？ |

**后者比前者重要得多。** 后来者唯一的胜算在增量上，不在存量上。

### Checklist（市场判断）

- [ ] 我能说出这个市场未来 3 年的核心增长驱动力（人口、政策、技术、代际、收入）
- [ ] 这个驱动力不是我的一厢情愿，能找到至少 2 个外部数据/案例支撑
- [ ] 我能解释为什么主流玩家还没进来（信息差？资源差？看不上？）

## 维度 3：未被满足的需求

差异化对了、市场在涨，但如果现有产品已经把用户伺候得很舒服，你做也是徒劳。所以要找**结构性的未满足需求**。

### 关键洞察：被忽略的角色 / 被忽略的场景

理想汽车的洞察：传统中大型 SUV 主要服务"前排司机 + 第二排老板"两个角色——但**家庭场景下，车里每个人都是平等的家人**。这就出现了大量未被满足的需求：

| 被忽略的角色 / 场景 | 创新方案 |
|---|---|
| 第三排乘客（老人/孩子）的舒适度 | **6 座 取代 7 座**（中间留通道，腿能伸） |
| 副驾家人的娱乐 | 多屏方案 |
| 后排孩子的视野 | 第三排前置无遮挡 |
| 全家出行半夜应急（孩子生病打不到车） | 自家车的"家庭兜底"价值 |

### 给你的方法

1. 列出你的目标人群的**真实使用场景**（不是平均场景，是高频场景 + 关键时刻场景）
2. 列出现有产品在这些场景中**默认服务的角色**
3. 找到"被忽略的角色 / 被忽略的场景"——这就是你的产品创新空间

## Playbook：定位决策 4 步

### Step 1: 收敛目标人群（最难，也最重要）

写下你的目标用户画像，然后**逼自己回答边界问题**：

> 例（理想汽车的真实讨论）：
> - "刚结婚没孩子的夫妻"算不算？
> - "夫妻没孩子但养狗"算不算？
> - "单亲父母带孩子"算不算？

**目标人群的描述必须细到可以做边界判断**——粗的描述（"年轻白领"、"中产家庭"）等于没收敛。

### Step 2: 找差异化维度

用本文「维度 1」的方法，找出二维矩阵的"无人区"。

### Step 3: 验证市场增长

用本文「维度 2」的方法，论证这个无人区背后的市场处于增长趋势。

### Step 4: 列出结构性未满足需求

用本文「维度 3」的方法，列出至少 **3 个**"竞品都没好好服务"的需求点——这些是你后续做产品的弹药库（功能创新、营销话术、用户教育的源头都在这里）。

## 拍板前 Checklist

- [ ] 我能用 1 句话说清楚目标用户是谁，**并且能做边界判断**（XX 算不算）
- [ ] 我的定位维度是新的——不是别人也在用的（价格、品类、模糊标签）
- [ ] 这个市场未来 3 年是涨的，**且我能说清楚增长驱动力**
- [ ] 我能列出 **3+ 个**现有产品没满足的结构性需求
- [ ] 这个定位在公司内部讨论时，**没人**用"听起来太小"作为反对理由（如果有，回到 Step 4 给增长论据 + 让反对方真正理解未满足需求的体量）

## 常见误区对照表

| 误区 | 真相 |
|---|---|
| "更大众的定位 = 更多销量" | 反——大众定位让你和所有人竞争，最后什么都不是 |
| "现在最大的市场 = 最值得做" | 反——存量大往往意味着饱和 + 在萎缩 |
| "用户调研说他们想要 X" | 用户提的是方案，不是需求。要追问"为什么想要 X" |
| "定位 = Slogan" | 反——定位是"为谁解决什么任务"的硬判断；slogan 只是表达层 |
| "定位定细了 = 限制自己" | 反——定位定细才能做出真正打动人的产品；定位粗等于不存在 |

## 输出物模板

完成定位后，应该能填出下面这段话——填不出说明前面某一步还没做扎实：

```
我们的产品是 [品类]，
为 [边界清晰的目标人群]
解决 [底层任务，不是表面功能]，
区别于现有竞品的 [差异化维度]。

支持论据：
- 市场增长：[驱动力 + 3 年趋势 + 外部数据]
- 未满足需求：[3+ 个结构性空白]
```
