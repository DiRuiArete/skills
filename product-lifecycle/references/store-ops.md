# 门店：直营销售的速度与平衡

> 智能电动车的销售为什么不能纯线上？为什么不能走传统经销商？理想用直营 + 数字化 + 收放平衡，把卖车做成了系统能力。本文给你的不是"卖汽车的方法"——是低频大额耐用消费品销售的通用逻辑。

> ⚠️ 这是本 skill 中通用度较低的一个 reference——主要适用于**线下重销售 + 大额低频耐用消费品**（汽车、家居、教育、医疗、保险）。软件 / 互联网产品可读但参考度低。

## 核心原则：低频大额必须线下

### 为什么纯线上走不通

理想的创始团队早年做汽车之家时就尝试过线上卖车——**投入最大、失败最惨的项目**。

反思失败原因：**低频大额消费品**纯线上走不通。

**底层逻辑**：
- 决策成本极高
- 决策周期极长
- 必须实际体验产品
- 新品牌往往需要多次体验才会决策

→ 汽车、房子是典型。线上能拿销售线索，但**最终成交是重线下生意**。

### 为什么不能走传统经销商

电动车成本结构 ≠ 燃油车：
- 同价位电动车成本 > 燃油车（更高配置 + 更高整车成本）
- 传统豪华品牌经销商综合成本（含降价促销）= **车标准零售价 20%**
- 这 20% **超过电动车毛利率** → 经营完全跑不通

**经销商怎么活下来？** 用售后服务利润补车价的低毛利。

但智能电动车：
- 几乎无保养成本
- 标配辅助驾驶 → 事故率远低于燃油车
- → **经销商的售后利润不存在**

→ **传统经销商体系养不活，必须直营**。

### 直营的目标

理想给自己定的硬指标：
- 把"卖一辆车的综合成本"从 20% **降到 5% 以内**
- 实现路径：直营 + 数字化（线上线下管理全数字化）
- 时间窗口：短期难，中长期可实现

## 经验 1：开店速度要快

### 反直觉的速度选择

正常做法：开店 → 单店做出效率 → 再开下一家。**理想 ONE 早期规划：2020 年开 20 家就够**。

但 2020 年战略会改变了一切：
- 2025 年要 160 万销量必要性目标
- + 一个发现：**有/无门店的城市，市占率差 8 倍**

→ 必须放弃"单店效率优先"，**速度优先**。

### 速度的真实数据

- 2020 年：从 5 家 → 60 家（3 倍增速）
- 2023 年 7 月底：超 400 家
- 平均：3 年来每年开 100 家

**单店效率**：开满半年的门店，**月均销量破百台，约为行业均值的三倍**。

### 怎么做到速度 + 效率兼得

#### 关键 1：少 SKU
车型 SKU 极少 → 销售和交付效率天然高。

> **给你的提示**：SKU 复杂度 = 销售复杂度。多 SKU 看似覆盖广，实际拖累每个店的效率。先简化产品线再扩张门店。

#### 关键 2：标准化培训 + 考试
所有销售人员**必须到北京和常州集中培训**：
- 怎么接待
- 怎么讲解产品
- 怎么销售
- 怎么使用后台系统
- **培训完封闭考试**，通过才能上岗
- 考试不通过 → 不录用

→ 人才素质和供给稳定，文化和产品理解一致。
→ 新店开业前，新人一起工作生活两周——回店里默契度好。

#### 关键 3：管理系统数字化
从源头线上到一线线下，数字化系统全面支撑销售 + 人员管理。

### 给你的方法

1. 算速度 vs 单店效率的取舍——基于必要性目标
2. 简化 SKU——不让产品线复杂度拖累门店效率
3. 集中标准化培训 + 考试上岗
4. 投资数字化系统支撑

## 经验 2：收和放的平衡

### 直营最大的问题：吃大锅饭

很多人以为直营最麻烦的是"占自有资金"。**错**——理想是订单预售模式，**只有应付没有应收**，现金流非常健康。

直营真正的麻烦：**门店多了之后吃大锅饭**——快速开店必然带来。

### 为什么吃大锅饭？

门店少 + 单一产品时：
- 总部销售管理团队每周带店长开会
- 营销活动怎么做、转化率怎么提 — 总部定标准
- 门店执行就行
- → 业务简单，总部能管细

门店几百家 + 多产品时：
- 总部管不了那么细
- 一刀切就资源错配

### 资源错配的真实数据

#### 例子：获客成本巨大差异

| 城市 | 线上获客成本 | 外展获客成本 |
|---|---|---|
| 一线城市 | 2000-3000 元 | 高 10 倍 |
| 西部城市（商圈集中） | 接近 20000 元 | 4000-5000 元 |

→ 一刀切分配资源 = **大量浪费**。

#### 例子：促销和激励

各地政策环境差异极大：同一台增程车，有的城市拿它限牌、有的城市反而发补贴——销售难度天差地别。

→ 促销和激励若全国一张表 = **必然错配**。

### 解法：让一线管理者分配资源

**销售工作的本质 = 两块**：
1. 获客（开店、推广、活动、外展、买线索）
2. 转化（降价、促销、招人、提高激励）

理想做法：

```
总部              省级负责人          店长
────              ──────              ──
提供数据          带店长做经营规划    建立本地市场感知
+ 必要管理        以市占率为目标      自定销量目标
                                     自判断资源投入
                                     执行 + 复盘
```

### 关键术语：投资组合

理想把"**投资组合**"当作经营意识的题眼——一线管理者要像打理一份投资组合那样打理自己手里的资源。

每个店长不是销售员，是这家店的 CEO。每个省级负责人是这个省的 CEO。

**Loop**：规划 → 计划 → 执行 → **复盘**（按周）

→ 听起来空洞的"经营意识"在循环里慢慢变成基础能力。

### 给你的方法

1. **算清楚地区差异化的获客 + 转化成本**——不要一刀切
2. **下放资源决策权到一线**（省级 + 店长）
3. **总部提供数据和管理工具**，不替一线做经营决策
4. **周复盘机制**——建立"投资组合"思维
5. **培养省级 CEO + 店长 CEO**——他们是真正的经营主体

## Playbook：建直营销售体系 5 步

### Step 1: 决策渠道模式
低频大额 → 直营。算综合成本：传统经销商模式跑得通吗？跑不通就直营。

### Step 2: 速度匹配必要性
基于战略目标倒推开店速度，不基于"单店效率优先"。

### Step 3: 简化 SKU + 标准化培训
SKU 少 + 集中考试上岗 + 数字化支撑。

### Step 4: 收放平衡
- 收：总部定数据、定流程、定培训
- 放：一线决定资源投入、目标定法、执行节奏

### Step 5: 周复盘 + 投资组合思维
每周规划 → 计划 → 执行 → 复盘循环。

## Checklist

- [ ] 我们算清楚了纯线上 / 经销商 / 直营的成本差异
- [ ] 我们的开店速度由战略必要性倒推，不是单店效率优先
- [ ] 我们的 SKU 是简化过的，不让产品线复杂度拖累门店
- [ ] 我们有标准化培训 + 考试上岗
- [ ] 我们用数字化系统支撑全链条
- [ ] 我们识别了不同地区的获客转化成本差异
- [ ] 我们下放了资源决策权到省/店级
- [ ] 我们的店长 / 省级有"投资组合"意识，不只是执行者
- [ ] 我们周复盘机制成了基础工作流

## 常见误区

| 误区 | 真相 |
|---|---|
| "互联网产品都能纯线上卖" | 错——低频大额必须线下 |
| "直营最大问题是占资金" | 反——预售模式现金流很健康，真正问题是大锅饭 |
| "总部一刀切最公平" | 错——地区差异巨大，一刀切就大量浪费 |
| "店长就是执行者" | 错——店长是这家店的 CEO，要有经营意识 |
| "速度和效率是 trade-off" | 短期是，但简化 SKU + 培训 + 数字化能兼得 |
