# 建品牌共识：用三个问题对齐用户

> 品牌不是名声，不是好产品做出来的副产物——**品牌是你跟用户提前建立的共识**。在动手做产品之前，就要把这个共识想清楚、说明白。

## 核心原则：品牌三问

品牌的所有理论再多，最后回到三个根问题：

```
1. 我们是谁？
2. 我们为谁服务？
3. 我们为他们创造什么价值？
```

这三问不是用来出 slogan 的，是用来对齐内部 + 对齐用户的硬决策。三问没答清楚就做产品，会越做越纠结，关键决策反复横跳。

## 三问展开

### 第一问：我们是谁？

**关键提示**：不要只考虑"想成为谁"，也要考虑"擅长什么"。

擅长什么 = 你的竞争优势 + 你能看清的领域 + 你和团队真实身份。理想团队做家庭车的隐藏优势：创始团队几个人加起来 10 来个孩子——他们自己就是产品的目标用户。

**给你的方法**：
1. 列出 3 个候选答案（"我是 X 公司"）
2. 对每个答案问自己：我有没有不可替代的优势？我自己是不是这个领域的真实用户？
3. 选有 2 个 yes 的答案

### 第二问：我们为谁服务？

**四个递进问题**（来自原方法论，定位是品牌的前置条件）：

| 问 | 验证什么 |
|---|---|
| 这个产品实际被谁使用？ | 要真实人群，不是想象出来的人群 |
| 这群人未来几年是扩张还是萎缩？ | 别把品牌押在萎缩市场上 |
| 他们有购买力、也愿意为此付费吗？ | 有需求 ≠ 会付费 |
| 你有低成本触达他们的通路吗？ | 触达成本过高的人群是个陷阱 |

**4 个 yes，才是真目标用户**。少一个，就要重新选。

### 第三问：创造什么价值？

**硬约束：答案必须简单直接，没有歧义。**

反例（汽车之家合并的"车 168"）："要做最有影响力的汽车网站"——团队对"最有影响力"的解读五花八门：有的说"专业"，有的说"在厂商有号召力"，有的说"用户评价高"。共识 = 0。

**正例**：
- 汽车之家：帮汽车消费者**看车、买车、用车**（直接进 slogan）
- 理想汽车：**移动的家，幸福的家**

清晰度的验证方法：**说给 10 个人听，他们脑子里浮现的画面要一致**。如果有 2 个人理解不一样，回去改。

## Playbook：建立品牌共识 4 步

### Step 1: 团队共创三问答案

不要 CEO 一人写——会变成自嗨。把核心团队（含产品、研发、运营）拉到一个会议室，每人独立写答案，再聚类讨论。

### Step 2: 用 4 问筛选目标用户

对候选目标人群，挨个回答上面的 4 个递进问题。任何一个 no 的就淘汰。

### Step 3: 把价值主张压缩到一个清晰的句式

模板：
```
我们是 [品类]，
为 [边界清晰的目标人群]
创造 [可被想象的具体价值]。
```

### Step 4: 跟用户达成共识（最关键的一步）

**品牌共识不是只挂在 slogan 里，要让用户在每个触点感知到**。

理想的做法：
- **产品功能选择**：不说"也可以"——"家庭出行也可以开"= 不彻底；要做就只为家庭做
- **宣传视角**：传统车厂从主驾视角拍，理想从二排/三排女主人和孩子视角拍——视角本身在传达"这车为全家"
- **每个触点**：销售话术、客服回应、APP 提示、车机交互——都要传达同一个共识

## Checklist（完成品牌定义后自检）

- [ ] 我能 1 句话说清楚我们是谁、为谁、创造什么价值
- [ ] 这 3 个答案在团队内部讨论过，不是 CEO 一人定的
- [ ] 我把价值主张说给 10 个人听，他们的想象基本一致（**实测**，不要假设）
- [ ] 我擅长这件事 / 我自己是这个产品的目标用户（至少满足一条）
- [ ] 在产品功能、宣传素材、销售话术里，能找到至少 3 个传达品牌共识的具体设计
- [ ] 我能拒绝"也可以服务 XXX 用户"的诱惑

## 常见误区

| 误区 | 真相 |
|---|---|
| "品牌就是 slogan + Logo" | 品牌是用户脑子里浮现的画面，不是文案 |
| "品牌是产品做好了自然就有的" | 反——品牌共识是产品决策的前置条件，不是结果 |
| "我们想成为高端品牌" | "想成为"不重要，"擅长什么"才决定能不能成为 |
| "我们 also 服务 X 人群" | "也可以"等于不彻底，会稀释品牌共识 |
| "品牌定义内部投个票就行" | 内部对齐只是第一步，不在用户每个触点传达就是 0 |

## 输出物模板

```
我们是 [品类]，
为 [目标人群—4 问验证过]
创造 [价值—10 人测试一致]。

我们的隐藏优势是 [团队真实身份 / 擅长领域]。

我们 NOT 服务 [明确排除的人群—防止稀释]。

3 个传达品牌的产品/触点设计：
1. [...]
2. [...]
3. [...]
```
