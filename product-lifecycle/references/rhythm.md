# 节奏：从 0→1 到 1→10 的目标与资源逻辑切换

> 创业者都不会轻视 0→1 的难度，但很多人到了 1→10 会松一口气觉得"不就是复制嘛"。**反——1→10 的目标逻辑、资源逻辑跟 0→1 完全不同，搞不清楚就让 1 没机会变成 10**。

## 核心原则：节奏 = 不同阶段不同打法

```
0 → 1 阶段                   1 → 10 阶段
─────────────                ─────────────
目标：放大长板               目标：必要性倒推（不是惯性）
资源：集中力量办大事         资源：宁可过度，不可不足
打法：游击队                 打法：集团军
失败成本：浪费时间金钱       失败成本：拿不到淘汰赛入场券
```

## 0 → 1 阶段

### 目标逻辑：把长板做成行业天花板

很多刚创业的人讨论"怎么跟头部正面对抗"——**为时过早**。

参考数据：2021 年蔚小理三家年销 9 万多辆——而长安/长城/吉利都是百万级。**蔚小理是头部的零头**。

这个阶段不是去比销量、比市场份额，**是尽全力放大自己的长板**：
- 蔚来：用户服务能力
- 小鹏：智能驾驶能力
- 理想：家庭用户群体的产品能力

**为什么长板能成长板？** 大多数是因为以前被领先者忽视了。**在没有规模优势 + 技术优势的时候，把长板做到天花板水平 = 拿到下一阶段入场券的唯一捷径**。

#### 入场券参考值

**3% 细分市场份额** = 合格线。

理想 ONE 选的细分市场是 25-50 万 SUV，2021 年 9 万销量 → 基本达到合格线。

### 资源逻辑：集中力量办大事

创业资源极有限、机会窗口极短暂——**不集中资源，长板做不到天花板**。

#### 反面教训：理想的 SEV 项目

理想最早规划**两条腿走路**：
- 增程式电动 SUV（理想 ONE）
- 低速电动小车 SEV（覆盖城市 50 公里出行，两座小车）

SEV 项目命运：
- 研发投入：2 年多、几亿资金
- 2018 年初**停掉**——政策不明朗，没法继续等
- 副作用：挤占理想 ONE 投入 → 2018 年下半年理想资金危机，**几乎命悬一线**

创始人事后复盘的判断：两条腿要是再走下去，公司大概率撑不到今天。

→ 理想总部**陈列的不是爆款**，而是 SEV 失败品——时刻提醒"集中力量办大事"。

### 0→1 给你的方法

1. 列出公司的 3-5 个候选方向
2. 砍到只剩一个——**最有差异化、最匹配资源**的那个
3. 所有资源砸向这一个，把它做到行业天花板
4. 在选定的细分市场达到 3% 份额 = 拿到入场券

## 1 → 10 阶段

### 目标逻辑：从惯性到必要性

到了 1→10 阶段，自然会顺着惯性想：未来一两年技术怎么升级？用什么新技术扩大战果？

**这个思路是错的。** 应该问的两个问题：
1. 未来市场究竟有多大？
2. 市场拐点什么时候到来？（拐点 = 赢家通吃、败者退场的时间点）

#### 真实案例：2020 年理想战略会

外部战略顾问在会上给出的关键提醒："不要顺着惯性看"。

讨论几轮得出结论：
- 中国智能电动车市场 **2025 年出现拐点**
- 拐点时市场规模 = 800 万辆/年
- 理想必须 ≥ 20% 市场份额 = **160 万辆/年**——才能拿到下一场比赛入场券

#### 必要性 vs 惯性的差距

2020 年理想销量 **3 万多**辆 → 5 年增长到 160 万 = **50 倍**——惯性看几乎不可能。

**但从必要性看，没得选**——

参考智能手机行业：十年前群雄混战，十年后 95% 以上的份额集中到了头部 5 家（苹果、小米、OV 系、华为荣耀）。智能电动车的门槛更高，收敛只会更狠，终局同样可能只剩 5 家。

要成为 5 家幸存者之一 → **160 万辆这个看似不可能的目标必须挑战**。能不能做到是一回事，**不准备等于在起点上就输了**。

### 资源逻辑：宁可过度，不可不足

百团大战幸存者留下的经验：

**对于淘汰赛，准备过度的资源浪费是有限的；准备不足永远会觉得当时打法偏保守、投入不够**。

#### 理想的 2020 年备战动作

基于 2025 必要性，从 2020 开始拼尽全力：

**第一步：单一爆品 → 多个爆品**
- L9 / L8 / L7 / L6 四款 SUV
- 覆盖 20-50 万更广价格地带
- 确保 SUV 市场绝对优势

**第二步：纯电产品线**
- 旗舰 MPV + 多款纯电 SUV
- 押注下一代高压快充（十来分钟补进约 500 公里续航）
- 关键判断：这项技术到 2023 年之后才算成熟——所以"此刻做纯电"和"当年做纯电"是两道完全不同的题

**同步动作**：供应链 + 产能也按必要性备战。

### 1→10 给你的方法

1. 把"未来 3-5 年的拐点"画清楚（市场规模、玩家数、淘汰格局）
2. 倒推"我必须达到什么状态才能活下来"
3. 从这个必要性反推**今天必须做什么**
4. 资源**宁可过度匹配**——保守 = 在起点上就输了

## Playbook：判断你处在哪个阶段 + 怎么切换

### Step 1: 自检阶段
- 还在打第一款产品 / 没拿到细分市场 3% 份额 → **0→1 阶段**
- 第一款已成功 / 在做多产品 / 接近淘汰赛节点 → **1→10 阶段**

### Step 2: 0→1 阶段执行
- 选 1 个最差异化方向
- 砍掉所有其他项目（哪怕已投入）
- 把长板做到行业天花板

### Step 3: 1→10 阶段执行
- 算清楚拐点（时间 + 规模 + 必要份额）
- 必要性倒推今天动作
- 资源宁可过度

### Step 4: 切换时机
- 已拿到 3% 入场券 → 准备切到 1→10 思维
- 切换信号：开始考虑"多产品"、"国际化"、"竞品淘汰格局"

## Checklist

### 0→1 阶段自检
- [ ] 我们只做一件大事，没有"两条腿走路"
- [ ] 我们的长板正在向行业天花板逼近
- [ ] 我们瞄准的细分市场，目标是 3% 份额合格线
- [ ] 我们没有为了"看起来全面"分散资源

### 1→10 阶段自检
- [ ] 我们算清楚了行业的拐点时间 + 规模
- [ ] 我们的目标是从必要性倒推的，不是惯性外推的
- [ ] 我们的资源是宁可过度匹配
- [ ] 我们的目标看起来"几乎不可能" — 这是必要性的特征

## 常见误区

| 误区 | 真相 |
|---|---|
| "0→1 时就要规划全产品矩阵" | 反——集中一个长板做天花板，其他都是分散 |
| "两条腿走路降低风险" | 错——分散注意力让两边都做不透 |
| "1→10 是 0→1 的复制" | 错——目标逻辑、资源逻辑完全不同 |
| "未来不可预测，跟着惯性走" | 错——必要性是看得见的（参考智能手机演化） |
| "宁可保守不要冒进" | 错——淘汰赛里保守 = 输在起点 |
