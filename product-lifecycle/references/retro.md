# 复盘：让爆品从偶然成为必然

> 一些品牌第一代产品惊艳，第二代不尽如人意，第三代进步，第四代又一塌糊涂——**进两步退三步**。原因：没有有效复盘，团队的成功经验没有沉淀成能力。

## 核心原则：复盘是把经验变成能力

### 关键反误区

很多人把复盘开成"批判会"——找哪里没做好、谁该背锅、互相甩锅。

**错。** 复盘的目标不是过去的赏罚，是**对"以后怎么更好"达成共识**。

正确顺序：

```
1. 先总结做得好的（成功经验沉淀，固化到流程）
       ↓
2. 团队被肯定后，会主动暴露不足（不需要外部批评）
       ↓  
3. 对照计划补短板（不是对照结果发散）
```

> **底层心理学**：先肯定团队做得好的，团队才敢于暴露不足。直接进入"哪里没做好"=团队进入防御模式。

### 关键结构：对照"计划"复盘，不是对照"结果"

很多复盘错在只看结果数据：
- 目标是 3% 市占率，结果 X% → 哪里掉链子？谁的锅？竞品怎么了？
- → **发散得没边**，到处错误归因

正确做法：**对照 PEA 计划复盘**。

PEA 在策划阶段已经把六维度想清楚了：
1. 解决什么问题（真问题论证）
2. 目标要求（用户能说出来的体验目标）
3. 方案描述（功能 + 实现方案）
4. 风险与评估（含预案）
5. 资源评估（研发资源 + 周期）
6. 运营指标（数据化 + 预期）

复盘 = **拿 PEA 一一对照**——哪条预期对了？哪条偏了？为什么偏？

**好处**：
- 没人能绕过真正重要的问题（PEA 是结构化的）
- 不会发散，焦点清晰
- 容易定位——是策划阶段错了，还是执行阶段错了

## 关键工具：每个问题落到具体 To-Do + 具体人

复盘的产出**不是会议纪要发到群里就完**——必须落到：
- 每个补短板 → 一条 To-Do
- 每条 To-Do → 一个具体负责人

**为什么落人**：不是为了追责，是为了**有人主动推进、迭代、迭代下一轮**。

→ 团队的成功经验沉淀成"超级智库"——下一款产品的人遇到类似问题，直接调用过去的沉淀。

## 怎么开好复盘会（清单）

### 5 条硬清单

#### 1. CEO / 一号位 / 业务负责人必参加
没有"我太忙了"——一号位不来，团队就不重视，复盘开成走过场。

#### 2. 专门的主持人
- 主持人**不参与讨论**——只把控方向
- 不是 CEO 兼任——CEO 兼任会变成 CEO 一言堂

#### 3. 会前布置作业
主持人提前跟关键参会者沟通：
- 解释复盘的价值
- 把会议讨论的重要问题告诉他们
- **让他们提前写下答案**

→ 现场不会卡壳，深度也会更深。

#### 4. 流程严格把控
- 每个问题，**每人/每组轮流发言一遍**，再开下一个问题
- 个别人不遵守 → 主持人**公开指出**并纠正
- 这一条很多复盘会没做到——会变成意见领袖单口秀

#### 5. 按时开，雷打不动
- 嵌入工作流——按周/月/季度/半年/全年
- 或按事件结点——产品研发/上市/发布完成
- **时间到就开**，不管推进顺不顺

### CEO 带头三个动作

清单看起来简单，"简单的事看不上，复杂的事做不到"是通病。CEO 必须带头做：

1. **上交手机**：会前主动交手机，要求所有人交手机——避免冗长，提高效率
2. **耐心倾听**：不张口否定他人发言，先在对方可取的点上阐述自己的想法
3. **随身记笔记**：每个人发言都记——这个习惯会潜移默化影响所有高管

## Playbook：复盘会 5 步

### Step 1: 先复盘"做得好"
- 把成功经验列出来
- 每条配数据 + 具体动作 + 避坑方法
- **固化到流程**（不是停留在 PPT 上）

### Step 2: 对照 PEA 找短板
六维度逐一对照，定位偏差点。

### Step 3: 每个问题落 To-Do + 人
不能"大家以后注意"——必须 [具体动作] + [具体负责人] + [完成时间]。

### Step 4: 复盘会执行 5 条清单
按上面的执行。

### Step 5: 沉淀到组织智库
所有复盘产出 → 可调用的"超级智库"。下一代产品起步时第一件事就是查智库。

## Checklist

- [ ] 我们先复盘"做得好"，再补短板（顺序不能反）
- [ ] 我们对照的是 PEA 计划六维度，不只是结果数据
- [ ] 每个问题都有 **To-Do + 具体负责人 + 时间**
- [ ] CEO / 一号位**亲自参加**，不是"代表参会"
- [ ] 有专门主持人，主持人不参与讨论
- [ ] 会前所有人**预先写下答案**
- [ ] 流程严格把控（轮流发言 + 主持人纠正）
- [ ] **按时开**，雷打不动嵌入工作流

## 常见误区

| 误区 | 真相 |
|---|---|
| "复盘 = 找问题、追责" | 错——复盘是把经验变成能力，先沉淀成功 |
| "对照结果数据复盘" | 错——对照 PEA 计划复盘 |
| "复盘会发了纪要就完事" | 没落 To-Do + 人 = 等于没复盘 |
| "CEO 太忙不参加" | 一号位不来，复盘就垮 |
| "讨论形式自由些" | 流程不把控就被意见领袖带跑 |
| "等需要再开" | 必须按时雷打不动——临时开等于不开 |
| "新错误也要惩罚" | 新错误不惩罚，重复错误才惩罚（出自结语） |
