# 利润：经营效率的三个抓手

> 重投入行业一旦现金流吃紧，后续生产严重受影响。李想的心态是把创业起点设在最深的那层地狱——能一路活着爬出地面，竞争力自然极强。本文给你三个抓手：精确预估 / 强硬把控 / 做好取舍。

## 核心原则

```
   精确预估（原子级拆分）
        +
   强硬把控（最佳实践逼近）
        +
   做好取舍（一切回到用户价值）
        =
   健康毛利率
```

### 硬指标：20% 毛利率

理想给自己定的目标毛利率 = **20%**——参考特斯拉等成功先行者。

为什么 20%：
- **必须保证 10% 研发投入**（智能电动车是高科技行业）
- **必要的管理 + 销售费用**
- 反推毛利率 ≥ 20%

> 毛利率不是数字游戏 — 是**研发能否持续投入**的源头。研发投入决定 5 年后的产品力。

---

## 抓手 1：精确预估（原子级拆分）

### 反模式：宏观平均值

大部分公司做利润测算：
- 每季度算一次（勤快的每月一次）
- 看哪部分成本高、哪部分费用高
- 决定下季度怎么管

**问题**：
- 结果**滞后**——一个月甚至一个季度后才知道有效性
- 只是宏观数据 — 一旦整体偏离，已经晚了

### 解法：拆到原子级

**原子级 = 拆到不能再拆的最小单元**。

**核心逻辑**：每个原子健康 → 整体就健康。

#### 例子：人员成本拆解

宏观做法："研发 + 销售需要多少人，平均薪酬，人效占比"——这是平均数。

理想的原子级做法：**倒推**。

```
目标：单个产品专家年薪高于行业水平
   ↓ 反推：他每月得成交几台
   ↓ 按成交转化率 → 每月要带多少场试驾
   ↓ 按试驾转化率 → 要握有多少条客户线索
   ↓ 线索处理 + 试驾安排合计工时
   ↓ 校验：工时在正常劳动强度内吗
```

每个环节都有数据推演——任何一环跟预期不符 → 立刻调整。

### 例子：销售收入拆解

大部分公司："根据市场状况估个数"——结果到揭晓时才知道。

理想做法：**多层市占率拆分**。

```
传播平台市占率
       ↓
客流市占率
       ↓
线索市占率
       ↓
订单市占率
       ↓
交付市占率
```

每一层一旦偏离预期 → 立刻干预、调整。

→ 经营利润率有非常精准预估，**不会出现到最后才发现意外成本**。

### 给你的方法

1. 列出你的核心成本 / 收入数据
2. 每条数据问："这个数能不能再拆？"
3. 拆到不能再拆为止——每个原子都有可监控指标
4. 建立每个原子的"预期值"
5. 跟预期不符 → 立即调整，不等季度结果

## 抓手 2：强硬把控（最佳实践逼近）

### 关键洞察：从"指标"到"案例"

只是评估精准还不够，还要在研发 / 生产 / 销售各环节做强硬把控。

强硬手段（管理）+ 数字化体系是基础。但**最有效的方式是提炼最佳实践**。

### 怎么提炼最佳实践

```
1. 用数据系统盯出各环节里数据最亮眼的人
       ↓
2. 把他们的具体动作总结成"案例"
       ↓
3. 分享给其他团队、其他人
       ↓
4. 大家逐渐接近最佳实践的最高值
       ↓
5. 半年刷新一次最佳实践（持续优化）
```

### 例子：电话预约试驾率最佳实践

某产品专家电话预约率特别高 → 把他的话术整理成纸面文本：逐句标出**重音与语调**，贴在工位屏幕旁，通话时照着提示走。

效果：大脑不用再背词，注意力全部用来把控语速、语调、停顿。

→ 几个月内大部分人都接近这个最佳实践的最高值。

### 解决"教会徒弟饿死师傅"

担心：人不愿意分享怎么办？毕竟"教会徒弟饿死师傅"。

理想的解：**制造场域，鼓励分享**。

#### 场域机制

- 每个层级**评选金牌、银牌、铜牌**
- 定期组织分享大会
- 在专门的分享场域里，分享欲望天然变强

→ 同事的优秀指标 + 经验留下来 → 最佳实践案例集 → 后人学习。

### 给你的方法

1. **建立指标体系**——所有人的数据可观察
2. **定期识别最佳实践**——数据最好的人/案例
3. **结构化总结**——具体动作、具体话术、具体数据
4. **建分享场域**——金银铜牌 + 分享大会
5. **半年刷新**——最佳实践要持续优化，不能固化

## 抓手 3：做好取舍（不刷存在感）

### 这一抓手最重要也最容易被忽略

费用和效率可以优化，但有些是硬成本——**怎么取舍是核心**。

### 反模式：产品经理刷存在感

产品经理最常见的通病：拿着"这个功能不错、这个材料上档次"来提议加配置。

李想的判断：**不要**。理由很直白：堆上去的冗余配置若换不来真实的产品价值，那不过是 PM 在给自己刷存在感——或者在照顾供应商关系。

### 经典案例：触摸灯不要改善

理想 ONE 二排顶部的触摸灯，到 L 系列立项时被 PM 提议"顺手升级一下"。李想只核实两件事：这个灯现状有毛病吗？有用户反馈过不满吗？两个答案都是否——提议当场被打回，定性为典型的刷存在感。

→ **没有用户反馈说不好的东西，不要花资源去改**。

### 怎么避免刷存在感：NPS 系统

理想建立详细的 NPS（净推荐值）系统：
- 详细记录每个用户在转推荐和反馈中**感知的功能点**
- 给功能赋予**权重**
- 研发计划严格按权重制定

→ 资源永远围绕真正的用户价值，不在重复建设/刷存在感的地方烧钱。

### 给你的方法

1. **每个新加的功能问**："有用户反馈说现状不好吗？没有 = 不要做"
2. **建立 NPS 或类似系统**——用户实际感知的权重数据化
3. **研发计划按 NPS 权重排序**——不是按 PM 想法排序
4. **抵御供应商关系 / 自己的偏好**——这些是噪音

### 控制欲望 + 管理安全感

取舍这门功课，李想归结为管住两样东西：欲望，和安全感。

**为什么？**
- **欲望**：PM 想加东西、想试新东西、想刷存在感
- **安全感**：怕"少做一个万一不够"——所以倾向于多做

控制好这两点 → 取舍清晰 → 利润才健康。

## 三抓手联动

```
精确预估              强硬把控              做好取舍
─────                ─────                ─────
原子级拆分            最佳实践逼近          回到用户价值
   ↓                    ↓                    ↓
预期偏差立即发现      所有人接近最佳值      不浪费在无价值功能
   ↓                    ↓                    ↓
─────────────────────────────────────────────
                    20% 健康毛利率
                          ↓
                    10% 研发投入
                          ↓
                    5 年后的产品力
```

## Playbook：经营管控 4 步

### Step 1: 算清楚必要毛利率
反推：研发投入比例 + 管理 + 销售 → 最低毛利率。

### Step 2: 原子级拆分
所有成本和收入数据拆到不能再拆，建预期值，偏差立刻调整。

### Step 3: 提炼最佳实践
建指标体系 + 找最佳值 + 总结案例 + 制造分享场域 + 半年刷新。

### Step 4: 严格取舍
基于 NPS 权重决定研发投入，每个新增功能问"用户有反馈吗"。控制欲望和安全感。

## Checklist

- [ ] 我们的目标毛利率是从研发投入 + 经营反推的，不是拍脑袋
- [ ] 我们的成本和收入都拆到原子级，每个原子有预期值
- [ ] 偏差不等季度——立即调整
- [ ] 我们建了指标体系，能看到谁的数据最好
- [ ] 我们提炼了最佳实践案例，并定期刷新（半年）
- [ ] 我们有分享场域（金银铜牌 + 分享大会）
- [ ] 我们有 NPS 或类似机制，赋予功能权重
- [ ] 研发计划按用户感知权重排序，不是按 PM 想法
- [ ] 我们能识别出"刷存在感"的功能并拒绝它

## 常见误区

| 误区 | 真相 |
|---|---|
| "毛利率是结果不是目标" | 错——毛利率是研发投入的源头，不能让步 |
| "宏观数据看趋势就行" | 错——要拆到原子级，否则发现问题就晚了 |
| "教会徒弟饿死师傅" | 错——制造分享场域，分享比藏私自利 |
| "好东西多加点没坏处" | 错——刷存在感的成本压垮利润 |
| "PM 想加这个功能" | 反问"有用户反馈吗"——没有就不加 |
| "成本控制 = 抠门" | 错——控制不必要成本 → 用在用户高感知功能 |
