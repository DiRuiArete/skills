# IPMS 流程图（产品营销与销售流程）

> Integrated Product Marketing & Sales — 从产品立项到用户使用的全周期管理。理想从华为学到的核心流程之一。营销 + 销售必须**从立项阶段就介入**，而不是临上市才参与。

## 用户价值流（一切流程的起点）

```
用户旅程 / 接触点：

  知道品牌 → 了解产品 → 产生兴趣 → 完成试驾 →
  产生购买意向 → 下单 → 交付 → 使用 + 服务

用户每个接触点的"第一诉求"：

  知道品牌：1 秒内 get 你是谁
  了解产品：3 分钟内知道是不是给我做的
  产生兴趣：能不能立刻互动（客服 / 试驾预约）
  完成试驾：预约后 ≤ 半天内有人响应
  产生意向：决策信息一站获取
  下单：流程顺、付款顺
  交付：交付承诺如期，体验仪式感
  使用 + 服务：问题响应快，不被踢皮球
```

> **硬约束**：所有内部流程要对应到上面的某个接触点。**不在用户价值流上的流程 = 删除**。

---

## IPMS 主流程节点（提炼版）

```
立项 → 概念 → 产品规划 → 工程开发 → 验证 → 量产 → 发布上市 → 售后管理 → 退市操盘

（对应华为 IPD 节点：Charter → CCP → CDP → PDP → VDP → DVP → PPDS → 生产 → 发布）
```

每个节点都有**两条支线必须并行**：

```
研发线（IPD）：    立项 → 概念 → 规划 → 开发 → 验证 → 量产
                    ↕↕     ↕↕     ↕↕     ↕↕     ↕↕     ↕↕  互锁
营销 + 销售线（IPMS）：从立项就介入 → 全周期管理 → 包括退市操盘
```

> **关键原则**：营销 + 销售线**不是临上市才介入**——从立项阶段就参与产品全生命周期管理。

## 各节点的关键产出

### 立项 / 概念阶段

研发线产出：
- 用户价值定义
- 竞品对标分析
- 技术路线选择

营销线产出：
- 目标人群画像（"边界判断级别"清晰）
- 品牌定位 + slogan 假设
- 上市节奏假设

### 产品规划阶段

研发线产出：
- 产品规格 PRD
- 功能优先级（基于 NPS 权重）
- 资源评估

营销线产出：
- 上市营销 KV 假设
- 渠道分配假设
- 老产品退市 / 衔接策略 ← **常被忽略！**

### 工程开发 / 验证阶段

研发线产出：
- 工程样车
- 关键功能验证
- 风险预案

营销线产出：
- 媒体策略
- 销售话术体系
- 一线培训方案
- 销售目标分解（按地区 / SKU）

### 量产 / 发布上市阶段

研发线产出：
- 生产爬坡
- 质量控制
- 软件 OTA 准备

营销线产出：
- 发布会执行
- 全国门店上市动作
- 试驾权益 + 客户激活
- 媒体投放
- 销售追踪 + 复盘

### 售后 / 退市操盘阶段（最容易遗漏）

研发线产出：
- OTA 升级
- 故障问题修复
- 用户反馈反哺新品

营销线产出：
- 老车主关怀
- **退市操盘**（新车上市时老车销量该如何处理）
- 库存清理
- 用户迁移

> **教训案例**：理想 L9 上市时 ONE 销量崩盘 + 老车主抗议——根本原因就是没有"退市操盘"流程。

## 互锁机制（关键节点的契约）

| 节点 | 互锁内容 |
|---|---|
| 立项 | 研发 + 营销 + 销售三方共同认可 PEA |
| 产品规划 | 销售目标已分解到地区 / SKU |
| 开发完成 | 营销物料 + 销售话术与产品同步 |
| 量产前 | 一线销售人员已完成集中培训 + 考试 |
| 上市前 | 老产品的退市操盘方案已就位 |
| 上市后 N 月 | 复盘机制启动（→ retro-template.md） |

> 互锁 = **从信任制升级为契约制**。各团队相互制约 + 密切协作。

## PDT 团队（重量级，不是个人）

PDT = Product Development Team。负责跨流程拉通的不是单个 PM，而是**重量级团队**：

```
PDT 团队组成：
  - 产品负责人
  - 研发代表
  - 市场代表
  - 财务代表
  - 采购代表
  - 制造代表
  - （其他业务线代表）
```

这个团队**共同为产品成功负责**——不是产品经理一个人传话。

## 路 vs 车

```
"路"（流程）= IPMS 这条主路
"车"（专业模型）= 支撑路上每个节点的专业模型

例：销售节点的"车" = 销售漏斗（传播 → 线索 → 试驾 → 成交）
例：定价节点的"车" = 产品价值公式（产品力 ÷ 价格 × 质量）
例：复盘节点的"车" = PEA 六维度对照
```

谁造车：各部门高级业务专家。
谁开车：一线员工。

**出问题区分**：路有问题修路、车有问题修车——不是开车人的责任。

## 实操建议

### 第一次建 IPMS 流程时

1. 先画**用户价值流图**（用户全周期的 8 个接触点）
2. 反推内部流程节点
3. 删掉不在用户价值流上的冗余流程
4. 定义每个节点的研发 + 营销双线产出
5. 建立**关键互锁点的契约**
6. 组建 PDT 重量级团队

### 已有流程升级时

1. 检查是否有"三不管地带"（如老产品退市操盘）
2. 检查营销 + 销售是不是从立项就介入了
3. 检查互锁点是不是契约制（不是只靠信任）
4. 检查 PDT 是不是重量级团队（不是只一个 PM）
