# 门店标准话术框架

> 销售话术不是死板背词——是**让一线员工把控好语气、节奏、关注点**的训练工具。理想的做法：把最佳实践打印 + 标注重音 + 贴在电脑上，**不再占用大脑内存**，更精准把控语音语调语速。

> ⚠️ 适用于**线下重销售场景**（汽车、家居、教育、医疗）。软件 / 互联网产品参考度有限。

---

## 框架

```
开场 →  发现关注点  →  对应价值传达  →  邀请下一步
  ↓         ↓             ↓                ↓
让对方     听 + 问       讲对方关注的     具体动作（试驾 / 预约）
舒服      不要预设       不是讲全部
```

每一步都要标注三个东西：
- **重音**（重读哪个词）
- **语调**（升 / 降 / 平）
- **节奏**（快 / 慢 / 停）

---

## 开场（10 秒内建立基本信任）

### 模板

```
您好（真诚），
我是 [品牌名] 产品专家（有精气神一点），
[姓名]（咬字清晰）。

看到您是关注咱们 [产品名] 对吧（[产品名] 重音）？
```

### 标注示例（虚构品牌示意）

```
您好（真诚 - 放慢 + 微笑），
我是星河家居的睡眠顾问（有精神 + 自信），
小林（咬字清晰）。

您是在看咱们的云感床垫这款对吧？
              ────────  ↑
              重音      升调（确认意图）
```

### 关键

- "真诚"——慢一点比快一点更真诚
- "精气神"——专业感的来源
- "咬字清晰"——名字记住才能后续连接
- 重复对方关注的产品名，用重音 + 升调 → 确认意图 + 让对方点头

## 发现关注点

### 反例：上来就讲产品

错误："我们这款车有 X / Y / Z 功能……"

→ 用户被信息淹没，**没有连接到他自己**。

### 正例：先听 + 问

模板问句：

```
"您是怎么了解到我们的？"
（建立连接，知道他的信息源 → 可以在话术中引用）

"您之前看过哪些车？"
（知道竞品对标，知道他在比什么）

"是您一个人开还是全家用？"
（确认目标场景，对应产品价值传达）

"平时主要在城市里开还是会跑长途？"
（确认使用频率，对应价值卖点）
```

→ **从他的回答中找出 1-3 个关注点**，下一步只讲这些。

### 关键

不要预设"我应该讲什么"——**预设了就讲不到他心里**。

---

## 对应价值传达

### 关键原则：讲他关注的，不讲全部

理想的产品价值有三层（来自第 5 讲）：
- 安全感（防守）
- 价值感（竞争）
- 向往感（口碑）

发现关注点后，对应到层：

| 用户关注 | 对应价值层 | 话术重点 |
|---|---|---|
| 安全 / 不踩坑 / 担心啥 | 安全感 | 突破行业惯性的安全设计（如副驾同级安全） |
| 同价位选哪个 / 配置对比 | 价值感 | 完整体验闭环（不是堆功能） |
| 想要的生活场景 | 向往感 | 嫁接他向往的画面（露营 / 客厅 / 家庭其乐融融） |

### 标注示例

```
"您说全家出行多对吧？
              ─── ↑
              重音 升调（呼应用户）

那我跟您讲个咱家的设计——
（停顿 + 拉近距离）

后排第三排的孩子，要从车门那侧上车的时候，
                                ─────
                                慢 + 平
不用挪第二排的座椅……
            ─────
            重音

为什么？因为咱们做的不是 7 座，是 6 座（重音）——
                                       ↓
                                    强调差异
中间留出通道，孩子直接走过去（手势 + 轻松语气）。
                          ─────────────
                          画面感
"
```

→ 不是背词，是**让用户脑海里出现具体画面**。

## 邀请下一步

### 关键原则：永远给出具体动作

错误："您先看看吧"——动作模糊，用户走了就走了。

正例：

```
具体动作 1：试驾邀约
"您要不要现在就坐进去试一下后排（具体）？
咱们刚好有车在这边（指向）。"

具体动作 2：留资 + 跟进
"您方便留下手机吗？我们这周末有个家庭日活动，
车主带着孩子来，您可以来现场感受下真实使用场景。"

具体动作 3：决策助力
"您之前看的 [竞品]，我可以帮您列一份对比清单 ——
重点是您关注的 [关注点]，方便您回家拿出来跟家人讨论。"
```

每一步动作要有：
- **明确时间**（现在 / 这周末 / 这周内）
- **明确动作**（坐进去 / 留手机 / 列清单）
- **明确价值**（让用户觉得不亏）

## 培训机制

理想的做法：
- 集中到北京 + 常州**封闭培训** 2 周
- 培训内容：接待 / 讲解 / 销售 / 后台系统
- 培训完**考试**——通过才能上岗
- 考试不过 → 不录用

→ 标准化人才输出 + 文化和产品理解一致。

→ 一起工作生活 2 周 → 回店里默契度天然好。

## 关键提醒

### 不要

- ❌ 死板背词（每个客户都不一样）
- ❌ 上来就讲产品（用户没连接）
- ❌ 讲全部功能（信息过载）
- ❌ 模糊邀请（"看看吧"）
- ❌ 跟客户辩论竞品（让客户自己判断）

### 要

- ✅ 标注重音 / 语调 / 节奏（解放大脑）
- ✅ 先发现关注点（听 + 问）
- ✅ 只讲他关注的（精准）
- ✅ 给具体动作（明确）
- ✅ 留下连接通道（手机 / 微信 / 下次）
