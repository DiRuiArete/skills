# 复盘记录模板

> 在 PEA 模板基础上加"复盘记录"和"Top-Do"两列。**对照计划复盘，不是对照结果发散**。

## 使用提示

- 复盘的对象 = 已经走完一轮的 PEA 评审项（产品功能 / 营销动作 / 项目）
- 复盘**不是找问题追责**——是把经验变成能力
- 先写"做得好的"，团队被肯定后才会主动暴露不足
- **每个问题必须落 To-Do + 具体负责人**

## 复盘会执行清单（贴在会议室）

```
[√] CEO / 业务一号位必参加（不是"代表参会"）
[√] 专门主持人（不参与讨论）
[√] 会前所有人提前写下答案
[√] 流程严格把控：每问题轮流发言一遍再下一题
[√] 不遵守 → 主持人公开纠正
[√] 按时开，雷打不动
[√] 会前所有人交手机
[√] 不张口否定，先在对方可取处阐述
```

## 关键提醒

### 顺序不能反

```
❌ 先批判 → 再肯定
✅ 先肯定（沉淀经验） → 团队主动暴露不足
```

### 对照不能错

```
❌ 对照"结果数据"（发散无边，错误归因）
✅ 对照"PEA 计划六维度"（结构化、聚焦）
```

### 落地不能虚

```
❌ "大家以后注意"
✅ [具体 To-Do] + [具体负责人] + [具体时间] + [跟进周期]
```

### 频率不能松

```
❌ "等需要的时候开"
✅ 按周/月/季度雷打不动开（嵌入工作流）
```

---

## 与下一次 PEA 的对接

```
本次复盘的成功经验
        ↓
固化到流程
        ↓
下一次 PEA 时直接调用 → 起点变高

本次复盘的失败教训
        ↓
进入"已知风险库"
        ↓
下一次 PEA 第四维度自动覆盖
```

→ 这就是李想说的"组织的成功经验沉淀成超级智库"。
