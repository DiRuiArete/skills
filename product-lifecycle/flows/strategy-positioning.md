# 定位流 — 产出：差异化定位语 + 用户边界判断 + 增长论证 + 未满足需求清单

## 输入
先查 plan 文件「已确认事实」：已有产品/品类与目标用户描述则复述确认后直接进 Step 2；缺什么补什么（一次只问一个）。

## 完成度锚点（本流 1-10）
1 有想法没描述 · 3 有产品+粗人群 · 4 边界判断中 · 5 边界+底层任务锁定 · 6 选定先攻维度 · 7 差异化维度收敛 · 8 增长论证完成 · 9 未满足需求清单成型 · 10 完整定位输出物

## Step 1：开场 + 收信息
输出：
```
✅ 进入定位流。
你的定位完成度：1/10（"刚开始想"，还没具体描述）

李想三维度框架：差异化 × 增长 × 未满足需求。
不需要现在懂——我会一步步带你做。

先收 2 个 1 句话信息：
1. 你的产品/品类是什么？
2. 你想到的目标用户是谁？

直接讲，不需要 ABC——我帮你压颗粒度。
```
等用户答。

## Step 2：颗粒度反问（3 选项决策点）
```
[复述：你说要做的是 "[XX 产品]"，目标用户是 "[YY 人群]"。]

✅ 完成度更新：1/10 → 3/10（有产品 + 粗用户描述）

⚠️ 检测到 2 个颗粒度问题：
1. "[用户的方案/产品]" 是你提的方案，可能不是用户真任务（钻头/洞/画框）
2. "[用户的人群]" 不够细到能做边界判断

【先攻哪个 — 3 选项】

★ A. 先压用户群边界（强烈推荐）
   完整度：9/10
   产出：边界清晰的细分人群（XX 算/不算）
   理由：人群不收敛 = 后续所有需求挖掘都失焦。这是"先定位"硬约束的第一步。

  B. 先挖底层任务
   完整度：7/10
   产出：用户的真实任务（钻头/洞/画框）
   理由：也很关键，但人群不清前挖任务容易跑偏。

  C. 直接进三维度框架
   完整度：3/10  ⚠️
   为什么低：基础没打就上框架 = 套模板做样子。

→ 我的推荐：A
回 A/B/C。
```

## Step 3：压人群边界
根据用户原描述派生 **3 个具体候选边界**：
```
✅ 完成度更新：3/10 → 4/10（开始边界判断）

我根据你的原描述派生 3 个候选——你帮我选一个最像，或者修改：

★ A. [候选 A 画像 + 付费意愿 + 高频痛点]（匹配度 9/10 + 理由）
  B. [候选 B 画像]（6/10 + 理由）
  C. [候选 C 画像]（8/10 + 理由）

→ 我的推荐：A
回 A/B/C，或者描述自己的细分。
```
边界压法（"XX 算不算"追问）展开读 references/positioning.md「Playbook：定位决策 4 步」Step 1。

## Step 4：挖底层任务（3 选项决策点）
```
✅ 完成度更新：4/10 → 5/10（人群边界清晰）
锁定：[用户选的边界]

现在挖底层任务——你最初说要做"[原方案]"，但这是方案。
他们具体卡在哪个底层任务？

【3 选项】（基于该人群的真实场景派生）
★ A. [底层任务 A]（最高频，付费意愿强）9/10 + 竞品与未满足空间
  B. [底层任务 B] 7/10
  C. [底层任务 C] 5/10

→ 我的推荐：A
回 A/B/C。
```

## Step 5：先攻哪一维（3 选项决策点）
```
✅ 完成度更新：5/10 → 6/10（人群+任务都清晰）
锁定：服务 [人群] 解决 [底层任务]

【先攻哪一维 — 3 选项】

★ A. 找差异化定位（构造新维度二维矩阵）
   完整度：9/10 · 产出：找到"无人区"
   理由：差异化是基础，没差异化就是挤进已经拥挤的格子。

  B. 验证市场增长趋势
   完整度：7/10 · 产出：3 年驱动力 + 数据支撑
   理由：增长重要但需要差异化做基础。

  C. 列结构性未满足需求
   完整度：6/10 · 产出：3+ 个产品弹药库
   理由：未满足建立在差异化定位之上。

→ 我的推荐：A
```

## Step 6-8：三维度逐维收敛
按 references/positioning.md 推进，每步派生 3 个具体候选（★ + X/10 + 1 句话理由），输出后停等拍板：
- 差异化维度（读「维度 1：差异化定位」）→ 完成度 7/10
- 增长验证（读「维度 2：高速增长的市场」）→ 8/10
- 未满足需求 3+ 条（读「维度 3：未被满足的需求」）→ 9/10

## 收尾（完成度 ≥9/10）
按 references/positioning.md「输出物模板」填完整定位，写入 plan 文件「流产出」节；对照「拍板前 Checklist」逐条勾验。
```
✅ 定位完成度：9/10
【下一步 — 3 选项】
★ A. 把定位翻译成品牌共识（9/10）——定位是内部判断，品牌是外部传达 → 继续：品牌流
  B. 直接进 0→1 做产品（6/10）——可做，但跳过品牌/标准 = 战略和产品脱节 → 回主菜单
  C. 整理一份可分享的定位文档（8/10）
→ 我的推荐：A
```
