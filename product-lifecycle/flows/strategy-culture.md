# 文化流 — 产出：3 条带真实案例的文化条目 + 灰度事件库 + CEO 守护机制

## 输入
先查 plan 文件「已确认事实」：已知团队年龄/规模/成功案例则直接进对应分支。

## 完成度锚点（本流 1-10）
0-3 团队 <1 年 ⚠️ 不要急着定 · 1 想做但没共创 · 3 共创发起 · 5 Top 3 提炼出 · 7 灰度事件库建立 · 9 CEO 守护机制运转 · 10 跨年度沉淀

## Step 1：开场 + 团队成熟度判断（3 选项决策点）
输出：
```
✅ 进入文化流。
原则：文化不是缺什么补什么——是从团队过往成功中提炼。

【先确认团队成熟度 — 3 选项】

★ A. 团队 1-3 年了，有几次成功案例 — 可以提炼了
   完整度：9/10 · 产出：3 条文化条目（每条配真实案例）+ 灰度事件库
   理由：沉淀一两年再提炼——这是文化生长的最佳时机。

  B. 团队 < 1 年 / 还没共性成功 — 别急着定文化
   完整度：3/10  ⚠️
   产出：暂不做（保留共识，先做事）
   理由：组织本来没有的基因装不进去。墙上贴标语 = 装饰品。
   建议：先做事，记录关键事件，1-2 年后再回来提炼。

  C. 团队 > 3 年，已有行为习惯 — 提炼+强化
   完整度：8/10 · 产出：提炼 + 灰度事件库 + CEO 培训守护
   理由：可做，但要警惕"已经形成的坏习惯"也是文化的一部分。

→ 我的推荐：A（如果你团队 1-3 年）
回 A/B/C。
```

## Step 2：提炼方式（3 选项决策点）
```
✅ 完成度：1/10 → 3/10
提炼方法：把所有元老聚到一起，回答"为什么我们能在这么短时间做出这种成绩？"

【提炼方式 — 3 选项】

★ A. 共创会（推荐）
   完整度：9/10
   做法：所有元老黑板上写候选条目，每条配真实案例，全员投票选 Top 3
   理由：共创出来的文化，团队天然认同。

  B. CEO 一人写
   完整度：3/10  ⚠️
   为什么低：变成"老板的一厢情愿"，团队不会真的认。

  C. 抄成功公司的（华为/苹果/字节）
   完整度：2/10  ⚠️
   为什么低：基因不一样，装上也不会发生作用。

→ 我的推荐：A
回 A/B/C。
```
共创会流程与硬约束（每条必须配真实案例）展开读 references/culture.md「提炼方法：所有元老共创 + 真实案例」。

## Step 3：灰度事件库（3 选项决策点）
```
✅ 完成度：5/10 → 7/10
文化提炼出来后最大问题是"灰度空间"——同一条准则每人理解不一样。
唯一解：在每个真实事件上做"选择题"。

【你下一步 — 3 选项】

★ A. 建灰度事件库（推荐）
   完整度：9/10 · 产出：记录"价值观冲突"事件 + 用选择题决策 → 沉淀价值排序
   理由：把对错题变成选择题（如"用户长期安全 vs 团队当下压力"），团队立刻共识。

  B. CEO 做文化 PPT 守护者
   完整度：8/10 · 产出：CEO 亲自维护文化 PPT，每周新员工培训亲自讲
   理由：文化要不停讲，CEO 是守护者。

  C. 把文化条目挂墙上 + 培训
   完整度：4/10  ⚠️
   为什么低：只挂墙不实战 = 装饰品。

→ 我的推荐：A + B 一起做
回 A/B/C。
```
灰度选择题的操作展开读 references/culture.md「落地：在具体事件上厘清灰度」。
