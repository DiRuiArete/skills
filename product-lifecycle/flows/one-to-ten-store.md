# 门店流 — 产出：渠道模式判断 + 开店速度规划 + 收放平衡机制

## 输入
先查 plan 文件「已确认事实」：先确认产品形态（线下重销售才适用本流）。

## 完成度锚点（本流 1-10）
1 渠道没定 · 3 适用性确认 · 6 直营策略定 · 9 收放平衡 + 投资组合 · 10 全闭环

## Step 1：开场 + 适用性检查（3 选项决策点）
输出：
```
✅ 进入门店流。

⚠️ 这个流适用于**线下重销售场景**（汽车、家居、教育、医疗）。
软件 / 互联网产品参考度较低。

【你的产品形态 — 3 选项】

★ A. 大额低频耐用消费品（继续）
   完整度：9/10——门店两条经验直接适用。

  B. 软件 / 互联网产品
   完整度：3/10  ⚠️——参考度低。建议改走利润流或流程流。

  C. 不确定 / 中间地带（B2B SaaS 重客户成功）
   完整度：6/10——参考"收放平衡"逻辑，跳过"开店速度"。

→ 看你产品选 A/B/C
回 A/B/C。
```

## Step 2：门店两条经验（3 选项决策点）
```
✅ 完成度：1/10 → 3/10
门店两条经验：
1. **开店速度要快**（必要性倒推，不是单店效率优先）
2. **收放要平衡**（总部一刀切 = 资源错配）

【你的痛点 — 3 选项】

★ A. 直营 vs 经销商怎么选（推荐）
   完整度：9/10 · 产出：商业模式判断 + 综合成本算账
   理由：基础决策。直营难，但毛利率必须够才跑得通。

  B. 开店速度 vs 单店效率怎么平衡
   完整度：8/10 · 产出：必要性倒推 + 标准化能力建设（少 SKU/标准化培训/数字化）
   理由：速度与效率兼得靠标准化，不靠取舍。

  C. 总部和一线怎么分权
   完整度：7/10 · 产出：收放平衡机制
   理由：投资组合思维。

→ 我的推荐：看阶段选
回 A/B/C。
```
两条经验展开读 references/store-ops.md「经验 1：开店速度要快」「经验 2：收和放的平衡」；渠道判断读「核心原则：低频大额必须线下」。

## Step 3：收放平衡 + 投资组合（3 选项决策点）
```
✅ 完成度：3/10 → 6/10
资源分配要交给一线管理者——不同地区获客成本可以差出数倍。
省级负责人 = 这个省的 CEO，每个店长 = 这家店的 CEO。

【你下一步 — 3 选项】

★ A. 建立"投资组合"经营机制（推荐）
   完整度：9/10
   做法：周复盘机制（规划→计划→执行→复盘）+ 一线决定资源投入
   理由："经营意识"在循环里慢慢变成一线的基础能力。

  B. 总部继续主导，一线只执行
   完整度：4/10  ⚠️
   为什么低：门店多了一刀切 = 大锅饭 + 资源错配。

  C. 完全放权，总部只看大数
   完整度：6/10
   为什么低：失去全局协同 + 标准化失控。

→ 我的推荐：A
回 A/B/C。
```
销售话术标准化另见 templates/store-script-template.md。
