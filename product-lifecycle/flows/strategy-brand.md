# 品牌流 — 产出：品牌三问答案（10 人测试通过）+ 共识传达触点设计

## 输入
先查 plan 文件「已确认事实」：已有定位输出（人群+底层任务+差异化维度）则直接进 Step 2 翻译；没有定位先提示走定位流。

## 完成度锚点（本流 1-10）
1 没想过品牌 · 3 有定位可翻译 · 5 三问答案选定 · 7 通过 10 人测试 · 9 共识传达机制定型 · 10 附 brand book

## Step 1：开场 + 你的状态（3 选项决策点）
输出：
```
✅ 进入品牌流。
你的品牌完成度估计：[根据用户描述给 1-3/10]

品牌的本质 = 跟用户提前建立的共识，3 个根问题：
1. 我们是谁？ 2. 我们为谁服务？ 3. 我们为他们创造什么价值？

【你现在的状态 — 3 选项】

★ A. 我有定位，帮我翻译成品牌三问
   完整度：9/10 · 产出：品牌三问答案（每个 1 句话清晰可识别）
   理由：定位是品牌的输入。有定位就能直接翻译，效率最高。

  B. 我没有定位，先给我品牌三问的框架
   完整度：5/10
   理由：没定位答品牌三问 = 答案模糊，10 个人听浮现 10 种画面。建议先走定位流（回主菜单选定位）。

  C. 我已经有 slogan，验证够不够清晰
   完整度：7/10 · 产出：用"10 人测试法"判断清晰度
   理由：slogan 验证是最后一公里，前提是定位 + 三问已清楚。

→ 我的推荐：A
回 A/B/C。
```

## Step 2：翻译定位 → 三问
```
✅ 完成度：1/10 → 3/10
请把你的定位发我（人群 + 底层任务 + 差异化维度）。
```
（plan 文件已有定位则跳过收集）收到后派生 3 个版本：
```
✅ 完成度：3/10 → 5/10（已有翻译素材）

我根据你的定位派生 3 个版本的品牌三问回答——你选最准的：

★ A. [版本 A：直接 + 工具感]（9/10）——直接对应定位，10 人测试一致性高
  B. [版本 B：愿景 + 情感]（7/10）——愿景感强，但容易 10 人浮现 10 种画面
  C. [版本 C：技术 + 差异化]（8/10）——差异化清晰，但可能限制品牌延展

→ 我的推荐：A
回 A/B/C，或修改。
```
三问的回答要领展开读 references/brand.md「三问展开」。

## Step 3：验证 + 共识传达机制（3 选项决策点）
```
✅ 完成度：5/10 → 7/10（三问答案选定）

硬约束：说给 10 个人听，脑子里浮现的画面要一致。
不仅自己定义清楚，还要让用户感知到。

【下一步 — 3 选项】

★ A. 做 10 人测试 + 修订
   完整度：9/10 · 产出：清晰度经过实测的三问答案
   理由：不测就是自嗨。

  B. 设计共识传达的 3 个产品触点
   完整度：8/10 · 产出：产品功能/宣传素材/销售话术里传达品牌的具体设计
   理由：品牌共识要在每个触点传达（视角本身就在传达定位）。

  C. 写 brand book / brand guideline
   完整度：6/10
   为什么不那么推：先验证再写，否则改的成本大。

→ 我的推荐：A → B（先验证再做触点）
回 A/B/C。
```
触点设计方法展开读 references/brand.md「Playbook：建立品牌共识 4 步」Step 4。

## 收尾（完成度 ≥9/10）
按 references/brand.md「输出物模板」填品牌输出，写入 plan 文件「流产出」节。
```
✅ 品牌完成度：9/10
【下一步 — 3 选项】
★ A. 翻译成产品标准（9/10）——品牌共识 → 产品标准是最关键转化 → 继续：产品标准流
  B. 进 0→1 做产品（7/10）——建议先做产品标准让团队有验收依据 → 回主菜单
  C. 做团队文化对齐（8/10）→ 继续：文化流
→ 我的推荐：A
```
