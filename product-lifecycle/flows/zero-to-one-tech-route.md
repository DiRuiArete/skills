```

2. 用户**绝不能接受**什么体验降级？
```
收到后：
```
✅ 完成度：3/10 → 6/10
你的红线：[复述]

★ A. 主流路线 + 关键改良（推荐）
   完整度：9/10
   做法：选行业主流，但找出"用户绝不能接受"的痛点做改良突破
   理由：不是照抄前人，是把关键短板补到红线之上。

  B. 非主流路线 + 取长补短
   完整度：8/10
   做法：组合两种技术互补
   理由：好的路线选择本质是组合而非"非此即彼"。

  C. 跟最酷的新技术
   完整度：4/10  ⚠️

```
